## 2. 結果を見た後に見つかった欠陥（追補 2）

`run.py --molgraph` が入力の pickle を idx 順のまま書いていた。学習のストリームは 256 件のブロックの中だけを並べ替える。ブロックの順はファイルの順のままなので、どの腕も毎エポック、ラベルの塊ごとに学習していた。訓練データの 256 件ごとの陽性率は次のとおり。
- BACE: 0.88 / 1.00 / 0.00 / 0.00 / 0.00
- BBBP: 0.58 / 0.73 / 0.66 / 1.00 / 1.00 / 1.00 / 1.00

影響は全ニューラル腕に及び、A0 には及ばない。調査段階の graph_only 試走は、エポックごとに全体を並べ替えて BACE 0.773 ± 0.027 だった。登録 run の A2 は 0.680 ± 0.016 で、この欠陥が性能を下げたことと合う。

## 3. 訂正後の再実行（70 run、2026-10-20 完了）

**結論（登録した規則による）: どちらのデータでも「融合が効く」「結合構造による」とは言えない。**

### 記述（判定には使わない）

- **行順の訂正の効果。** ニューラルの腕はほぼすべて上がった（BACE の A1 は 0.744 → 0.805、A2 は 0.680 → 0.745）。A0 は登録 run と同じ値で、影響を受けていないことと合う。BBBP の A3 だけは 0.663 → 0.637 と下がった。
- **グラフ単独は結合を使っている。** A2 − A2e は BACE で +0.057 [+0.019, +0.104]（best）、+0.096（final）。BBBP では +0.014 で、差は示されない。
- **融合の中では結合が効いていない。** A3 − A3e と A3 − A3s は、両データ・best / final のどれでも区間が 0 をまたぐ。グラフ単独では結合構造が効くのに、テキストと融合するとその寄与が見えなくなる。
- **BBBP では融合がテキストのみより低い傾向。** best −0.049、final −0.052。補正前の p はどちらも 0.026 だが、Holm 後は 0.104 で、判定の規則では差は示されない。
- **指紋の床。** BACE では A0（0.853）がどのニューラル腕よりも高い（A3 − A0 は −0.042、p 0.122）。BBBP では、テキストのみの final（0.727）が A0（0.677）より高い（探索的）。

### 読み方

- テキストのみ（A1）がグラフのみ（A2）より強い。グラフ単独は結合構造を使える。それでも、融合しても A1 を超えず、融合の中では結合の有無で差が出ない。コード（BigVul）の観察と同じ形。
- 2D の分子グラフは SMILES から決まるので、グラフが運ぶ情報はテキスト側にもある。この結果は「グラフは LM が使えない情報を運ぶときだけ効く」という仮説と矛盾しない。
- ただし、別の 2 つの説明とは区別できていない。
  - 情報が重複しているので足すものがない。
  - この融合の仕組み（並列の枝＋cross-attention＋ゲート）が、グラフ側を使えていない。
- 限界:
  - test は 152 / 204 分子と小さい。
  - 5 seed・30 エポック、テキストモデルは小型（77M）、融合の仕組みは 1 種類。
