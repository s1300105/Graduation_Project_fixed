# Attention "sharpness": entropy, rank, sinks, dispersion with length, temperature and sparse alternatives (theory + measurement, 2016–2026)

Scope note: this file is a citation-backed catalogue + synthesis. Every item has a URL. Items I could not open in full are marked "(abstract only)" or "(unverified)". Formulas marked "verbatim" were read from the paper text (arXiv HTML or pdftotext of the official PDF); others are paraphrases of the paper's statement. Notation: n or T = number of keys (sequence length / support size), α_k = attention weight on key k, H = Shannon entropy of one attention row.

## Key Question 0 — Catalogue of papers (title, authors, venue/year, quantity defined, theory, empirical setting, remedy, URL)

### Takeaway
Across ~40 papers the recurring "sharpness" quantities are: (i) row entropy H(A_i) = −Σ_j A_ij log A_ij (raw, or normalised by log n), (ii) max attention weight / "confidence", (iii) mass on a designated token (attention-sink rate with threshold ε), (iv) rank-type measures (residual to rank-1, effective rank = exp(entropy of normalised singular values), rank(φ(Q)φ(K)ᵀ) ≤ min(n,d)), and (v) spectral gap / log-normal variance. The formal "softmax must disperse" results all share one mechanism: bounded logit spread δ ⇒ each α_k ∈ [e^{−δ}/n, e^{δ}/n] ⇒ Θ(1/n) weights and entropy → log n.

### Cited Findings (one record per paper)

**A. Softmax dispersion with input size / length-aware scalings**

- **Softmax is not Enough (for Sharp Size Generalisation)** — Petar Veličković, Christos Perivolaropoulos, Federico Barbero, Razvan Pascanu — ICML 2025 (arXiv v1 Oct 2024, v3 May 2025). *Quantity:* attention coefficient α_k^(n), Shannon entropy H = −Σ p_i log p_i of the attention row; "sharp" function = output expressible from a constant number of inputs (max is sharp, average is not). *Theory (verbatim structure):* Lemma 2.1 — if logits satisfy m ≤ e_k ≤ M, δ = M−m, temperature θ>0, then for every k: (1/n)·exp(−δ/θ) ≤ α_k^(n) ≤ (1/n)·exp(δ/θ), i.e. α_k^(n) = Θ(1/n). Theorem 2.2 — with a finite input vocabulary and continuous FF/attention layers, for any θ>0, ε>0 there is n such that softmax_θ(e^(n))_k < ε for all k ("attention coefficients must disperse in all global Transformer heads if the input vocabulary is finite"). Proposition 3.1 — δ ≤ 2·σ_max(Q)·σ_max(K)·‖y‖·max_i‖x_i‖ (sharpness needs large weights). Proposition 3.2 — dH/dβ = −β·Var(e) for p_i ∝ exp(−β e_i): entropy is maximal at β=0 (uniform) and monotone in |β|. *Remedy:* inference-time adaptive temperature: θ ≈ 1/(−1.791 + 4.917H − 2.3H² + 0.481H³ − 0.037H⁴), applied as β = max(polyval(fit,H), 1.0) when H > 0.5, never raising θ above 1 ("we do not wish to increase entropy"). *Empirical:* single-head max-retrieval trained on set sizes 5–16, tested to 16,384 items (baseline accuracy 97.1 → 12.4 %, adaptive-θ 97.1 → 14.0 %); Gemma 2B fine-tuned on 30 CLRS-Text algorithmic tasks (adaptive temperature used in fine-tuning and inference). — [arXiv abs](https://arxiv.org/abs/2410.01104); [HTML v3 (formulas)](https://arxiv.org/html/2410.01104v3)

- **Scalable-Softmax Is Superior for Attention (SSMax)** — Ken M. Nakanishi — arXiv Jan 2025 (no peer-reviewed venue listed). *Quantity:* largest softmax output ("attention fading"). *Theory:* for logits with max z_max, min z_min, max_i softmax(z)_i ≤ 1/((n−1)·e^{−(z_max−z_min)} + 1) → 0 as n→∞. *Remedy:* SSMax replaces e^{z_i} by n^{s z_i}, i.e. Softmax((s·log n)·qKᵀ/√d) with s a learnable scalar per layer/head; with SSMax the top weight → 1 when z_max − z_2nd > 1/s and spreads when all logits lie within ≈1/s. A variant with an extra bias b (exponent (s log n + b) z_i) hurt long-context performance. *Empirical:* 162M-param, 12-layer model on SlimPajama, train length 1024; after RoPE θ 10k→500k without retraining, SSMax kept lower per-position loss out to ≈10× training length and solved needle-in-a-haystack at ≈10× training length where softmax failed "beyond short context sizes". — [arXiv abs](https://arxiv.org/abs/2501.19399); [HTML](https://arxiv.org/html/2501.19399v1)

- **Overcoming a Theoretical Limitation of Self-Attention** — David Chiang, Peter Cholak — ACL 2022 (pp. 7654–7664). *Quantity:* cross-entropy of the classifier as a function of string length; attention weight on position 1. *Theory:* builds on Hahn's result that for languages whose acceptance depends on a single symbol (FIRST), "a transformer's classification decisions become less and less confident (that is, with cross-entropy approaching 1 bit per string) as input strings get longer" (verbatim). Fig. 4 discussion (verbatim): "the lower n is, the more the attention weight is diluted, making it easier for the value in position 1 to be outweighed by values in other positions." *Remedy (Section 5.3, verbatim):* "scaling the logits of each attention layer by log n", Att(q,K,V) = Vᵀ softmax((log n/√d) K q); Proposition 3: with this scaling, with or without layer norm, a transformer recognises FIRST with cross-entropy ≤ η for any η>0. *Empirical:* PARITY/FIRST and MT (scaling helps when training on short and testing on long sentences). — [ACL Anthology](https://aclanthology.org/2022.acl-long.527); [arXiv](https://arxiv.org/abs/2202.12172)

- **Theoretical Limitations of Self-Attention in Neural Sequence Models** — Michael Hahn — TACL 2020. The origin of the "confidence decays with length" result used by Chiang & Cholak (hard-attention cannot model PARITY; soft-attention cross-entropy approaches chance for single-symbol-dependent languages). (From memory of the paper; URL verified only by identifier, content not re-fetched in this session: treat statement as needing a check.) — [arXiv 1906.06755](https://arxiv.org/abs/1906.06755)

- **Long-Context Generalization with Sparse Attention (α-entmax / ASEntmax)** — Pavlo Vasylenko, Hugo Pitorro, André F. T. Martins, Marcos Treviso — arXiv Jun 2025, v4 Mar 2026; a third-party mirror header says "Published as a conference paper at ICLR 2026" (venue not shown on arXiv page). *Quantity (verbatim definition):* dispersion = H(f(z_1:n))/log n (normalised entropy); "complete dispersion" if the ratio → 1 for any bounded logits; "concentration resilience" if it stays < 1 for some bounded logits. *Theory:* softmax exhibits complete dispersion at any fixed temperature (normalised entropy → 1); α-entmax entropy is bounded by O(log s) with s = support size; if support grows as O(n^β), β<1, normalised entropy ≤ β; adding a token can leave existing α-entmax probabilities unchanged, which softmax cannot do. *Remedy:* ASEntmax — each head scales logits by a query-dependent factor (δ + β(log n)^γ) before α-entmax (β>0 via softplus, γ bounded via scaled tanh; β=0 recovers α-entmax); default positional scheme "NAPE" = half heads NoPE, half ALiBi. *Empirical:* MQMTAR synthetic recall trained at length 64, tested up to 1024× (≈65K tokens), ASEntmax 95.3 % at the longest length vs softmax / top-k / SSMax / fixed α=1.5 entmax baselines; 420M LLaMA-3-style LM on DCLM-Edu (77B tokens, context 2048) with perplexity still decreasing on ArXiv out to 8× training length, RULER NIAH. — [arXiv abs](https://arxiv.org/abs/2506.16640); [HTML v4](https://arxiv.org/html/2506.16640v4)

- **Length Generalization of Causal Transformers without Position Encoding** — Jie Wang, Tao Ji, Yuanbin Wu, Hang Yan, Tao Gui, Qi Zhang, Xuanjing Huang, Xiaoling Wang — arXiv Apr 2024 (venue not on arXiv page; reported elsewhere as ACL 2024 Findings — unverified). *Quantity:* per-head entropy at query position i, H_i^(h) = −Σ_{j=1}^{i} α_ij log α_ij, averaged over validation samples and heads; max entropy at position i is log i (uniform). *Finding:* "the lower layers have high entropy, closely approaching the upper bound"; failure of NoPE beyond training length coincides with rising entropy ("attention distraction"). *Remedy:* temperature scaling with frozen weights — UniformScale (one λ = c/√d for all heads): ≈1.2× scale for 2× length, ≈1.5× for 4×, ≈1.8× for 8×; HeadScale (704 per-head scales for a 22-layer × 32-head model, tuned on in-distribution data at target length) generalises better. For RoPE "the inflection points of entropy curves remain almost unchanged" under scaling 0.8–1.4 and it "fails to generalize to longer lengths". — [arXiv abs](https://arxiv.org/abs/2404.12224); [HTML v2](https://arxiv.org/html/2404.12224v2)

- **从熵不变性看Attention的Scale操作 (Su Jianlin blog, Dec 2021)** — proposes an "entropy-invariant" attention scale proportional to log n (replacing 1/√d by κ·log n/d) so that attention entropy does not drift with length; frequently cited as the origin of log-n scaling in Chinese-language LLM work. **Unverified in this session:** both kexue.fm and spaces.ac.cn returned HTTP 403, so the exact constant κ and derivation could not be confirmed. — [kexue.fm/archives/8823](https://kexue.fm/archives/8823)

- **YaRN** (Peng et al. 2023) uses a length-dependent attention temperature (1/√t = 0.1·ln(s) + 1 with s the context-extension factor) — from memory, not re-fetched; mark unverified. — [arXiv 2309.00071](https://arxiv.org/abs/2309.00071)

**B. Entropy collapse / entropy as a training diagnostic**

- **Stabilizing Transformer Training by Preventing Attention Entropy Collapse** — Shuangfei Zhai, Tatiana Likhomanenko, Etai Littwin, Dan Busbridge, Jason Ramapuram, Yizhe Zhang, Jiatao Gu, Josh Susskind — ICML 2023 (PMLR 202, pp. 40770–40803). *Quantity (verbatim):* Ent(A_i) = −Σ_{j=1}^T A_ij log A_ij; Ent(A) = (1/T)Σ_i Ent(A_i), averaged over query positions, heads, examples. *Theory (Theorem 3.1, verbatim):* with σ = ‖W_K W_Qᵀ‖₂, σ_x = ‖XXᵀ‖₂, σ̄ = σσ_x, β = exp(−σ̄√(T/(T−1))): Ent(A_i) ≥ log(1 + (T−1)β) + σ̄√(T(T−1))·β/(1 + (T−1)β); bound is tight; "for large σ,T, the minimum attainable entropy behaves like Ω(Tσe^{−σ̄})". *Remedy:* σReparam, Ŵ = (γ/σ(W))·W with learnable γ (init 1), spectral norm by power iteration. *Empirical:* ViT (trained without warmup, weight decay, LN or adaptive optimizer), SSL, MT, ASR, LM. — [arXiv abs](https://arxiv.org/abs/2303.06296); [HTML v2](https://arxiv.org/html/2303.06296v2)

- **Variance Sensitivity Induces Attention Entropy Collapse in Transformers** — Jonghyun Hong, Sungyoon Lee — EMNLP 2025 (main, paper 421). *Quantity (verbatim Eq. 6–7):* H(P_i) = −Σ_{j=1}^N P_ij log P_ij; H(P) = (1/N)Σ_i H(P_i); uniform rows give the maximum log N; ‖P‖_F reaches its maximum √N at collapse. Explicitly contrasts row-wise entropy with the column-wise sink metric of Gu et al. ("The sink metric computes attention column-wise over K, thereby discarding row-wise information"). *Theory:* high variance-sensitivity of softmax is the cause of collapse; ReLU-kernel attention is "theoretically entropy-stable" (entropy insensitive to logit variance); concentration raises ‖P‖ and causes gradient explosion. *Remedy:* ReLU kernel attention or QK-LayerNorm. — [ACL Anthology PDF](https://aclanthology.org/anthology-files/pdf/emnlp/2025.emnlp-main.421.pdf)

- **ReLU's Revival: On the Entropic Overload in Normalization-Free Large Language Models** — Nandan Kumar Jha, Brandon Reagen — NeurIPS 2024 workshop (ATTRIB), arXiv Oct 2024. *Quantity:* attention-head entropy; "entropic overload" in early layers = heads near maximal entropy, read as under-used head capacity (the opposite failure to collapse). *Remedy:* ReLU instead of GELU in LN-free decoders (8.2 % perplexity gain). (abstract only) — [arXiv abs](https://arxiv.org/abs/2410.09637)

- **Self-Attention Limits Working Memory Capacity of Transformer-Based Models** — Dongyu Gong, Hantao Zhang — NeurIPS 2024 Behavioral ML workshop, arXiv Sep 2024. *Quantity:* total entropy of the causal attention matrix. *Finding:* entropy rises as N-back difficulty N grows and accuracy falls; 1-layer/1-head models' accuracy drops logarithmically in N; framed as a hypothesis on toy models. — [arXiv abs](https://arxiv.org/abs/2409.10715); [NeurIPS page](https://neurips.cc/virtual/2024/102121)

**C. Rank collapse / over-smoothing / over-squashing**

- **Attention is Not All You Need: Pure Attention Loses Rank Doubly Exponentially with Depth** — Yihe Dong, Jean-Baptiste Cordonnier, Andreas Loukas — ICML 2021 (PMLR 139; arXiv v2 Aug 2023). *Quantity (verbatim):* res(X) = X − 1xᵀ with x = argmin_x‖X − 1xᵀ‖; ‖X‖_{1,∞} = √(‖X‖₁‖X‖_∞) ("not a proper norm"); empirical protocol = relative residual ‖res(SAN(X^l))‖_{1,∞}/‖SAN(X^l)‖_{1,∞} per layer on BERT/ALBERT/XLNet, 32 Wikipedia biography excerpts of 128 tokens. *Theory (Theorem 2.3, verbatim):* for depth-L, width-H SAN without skips, ‖res(SAN(X))‖_{1,∞} ≤ (4γβH/√d_qk)^{(3^L−1)/2}·‖res(X)‖_{1,∞}^{3^L}, with ‖W_QK‖₁‖W‖_{1,∞} ≤ β and γ depending on attention entries; convergence guaranteed when 4γβH < √d_qk. MLP Lipschitz constant λ enters as (4γβHλ/√d_qk); skip connections: only a lower-bound counterexample (Claim 3.1), tight bound "an open challenge". — [arXiv abs](https://arxiv.org/abs/2103.03404); [HTML v2](https://arxiv.org/html/2103.03404v2); [PMLR (venue, not fetched)](https://proceedings.mlr.press/v139/dong21a.html)

- **Signal Propagation in Transformers: Theoretical Perspectives and the Role of Rank Collapse** — Lorenzo Noci et al. — NeurIPS 2022 (arXiv 2206.03126). Rank collapse at initialisation makes query/key gradients vanish; softmax inverse temperature directly controls Q/K gradient magnitude; remedy = depth-dependent residual scaling. (Search snippets + proceedings abstract only.) — [NeurIPS proceedings](https://proceedings.neurips.cc/paper_files/paper/2022/hash/ae0cba715b60c4052359b3d52a2cff7f-Abstract.html)

- **Revisiting Over-smoothing in BERT from the Perspective of Graph** — Han Shi, Jiahui Gao, Hang Xu, Xiaodan Liang, Zhenguo Li, Lingpeng Kong, Stephen M.S. Lee, James T. Kwok — ICLR 2022 (Spotlight). Self-attention matrix viewed as a normalised adjacency matrix; if LayerNorm's standard deviation is large enough the stack converges to a low-rank subspace; remedy = hierarchical fusion. (abstract only; the token-cosine-similarity metric is from memory, unverified here.) — [arXiv abs](https://arxiv.org/abs/2202.08625)

- **Transformers need glasses! Information over-squashing in language tasks** — Federico Barbero, Andrea Banino, Steven Kapturowski, Dharshan Kumaran, João G.M. Araújo, Alex Vitvitskyi, Razvan Pascanu, Petar Veličković — NeurIPS 2024 (per task brief; arXiv page lists no venue). *Quantities:* representational collapse ‖v_n^(L) − v_{n−1}^(L)‖ for a growing prefix with repeated last token; over-squashing = Jacobian ‖∂y_n/∂v_i^(0)‖ bounded by a sum over causal paths of attention products. *Theory:* Theorem 4.2/B.3 — the length-n sequence and the length-(n+1) sequence with repeated last token get arbitrarily close final-token representations as n→∞ (needs bounded representations, positional encodings decaying with distance; no explicit rate; "Nothing in the paper supports a 1/n decay"); Lemma B.1 — softmax weight on the appended token vanishes as n grows (qualitative); Prop. 5.2/B.8 — as L→∞ the output depends only on the first token; bf16 makes collapse happen sooner. *Remedy:* insert extra tokens (commas every third digit) to keep representations apart. *Empirical:* Gemini 1.5 counting/summing/copying of 0/1 strings; Gemma 7B last-layer representation distances. — [arXiv abs](https://arxiv.org/abs/2406.04267); [HTML v2](https://arxiv.org/html/2406.04267v2)

- **Why do LLMs attend to the first token?** — Federico Barbero, Álvaro Arroyo, Xiangming Gu, Christos Perivolaropoulos, Michael Bronstein, Petar Veličković, Razvan Pascanu — arXiv Apr 2025, v4 Aug 2025 (venue not listed on arXiv). *Quantities (verbatim):* sensitivity ‖J_ij^(L)‖ = ‖∂v_j^(L)/∂v_i^(0)‖; sink rate = (1/(LH))Σ_{h,ℓ} 1((1/T)Σ_j α_1j^(ℓ,h) > ε) with default ε = 0.3, and ε = 0.8 for the LLaMa 3.1 analysis (T = 64, 170 prompts). Rank collapse: ‖V^(L) − (1/n)11ᵀV^(L)‖_F < Δ; representational collapse: ‖v_n^(L) − v_{n−1}^(L)‖₂ < Δ; Prop. 3.1: rank collapse at Δ/2 ⇒ representational collapse at Δ (converse fails); rank collapse is "a statement about depth", representational collapse "about context length". *Theory (Theorem 3.2):* ‖∂v_j^(L)/∂v_i^(0)‖ ≤ C_max^L·Σ_paths Π ᾱ with ᾱ_ij = Σ_h α_ij^(ℓ,h) + δ_ij/H — mass on the sink lowers the mixing bound (qualitative; assumes Q/K independent of V, no derivative through softmax). *Empirical:* ≈120M LLaMa-2-style models (5B tokens): "essentially no sink formation at a context length of 128", sink rate rises with pre-training context length until saturation; LLaMa 3.1 8B/70B/405B sink metric 45.97 / 73.49 / 78.29 (ε = 0.8); Gemma 7B: removing ⟨bos⟩ smooths attention maps and drops ARC-e 80.77→28.49, RULER-4096 82.57→0.00; data packing: fixed ⟨bos⟩ 90.84 % sink (and 0.05 % / loss 7.56 when ⟨bos⟩ removed at inference), no fixed ⟨bos⟩ 65.15 %, intra-doc masking 50.24 %. — [arXiv abs](https://arxiv.org/abs/2504.02732); [HTML v4](https://arxiv.org/html/2504.02732v4)

- **Demystifying Oversmoothing in Attention-Based Graph Neural Networks** — Xinyi Wu, Amir Ajorlou, Zihui Wu, Ali Jadbabaie — NeurIPS 2023 (spotlight). Theorem 1: under assumptions A1–A4 node representations converge exponentially with depth for attention-based GNNs (random-walk GCN, GAT, graph transformers); attention re-weights but cannot change the connectivity of the aggregation operator. (abstract/snippets) — [arXiv](https://arxiv.org/abs/2305.16102); [NeurIPS](https://proceedings.neurips.cc/paper_files/paper/2023/hash/6e4cdfdd909ea4e34bfc85a12774cba0-Abstract.html)

**D. Attention sinks**

- **Efficient Streaming Language Models with Attention Sinks** — Guangxuan Xiao, Yuandong Tian, Beidi Chen, Song Han, Mike Lewis — ICLR 2024. *Quantity:* attention mass on initial tokens ("sink": strong attention to initial tokens that are not semantically important). *Explanation:* softmax must sum to one, so surplus mass is dumped on early, always-visible tokens (from the paper body; the abstract page does not state it). *Remedy:* keep initial-token KV + sliding window (StreamingLLM); a dedicated placeholder sink token in pre-training. *Empirical:* Llama-2, MPT, Falcon, Pythia, up to 4M tokens, 22.2× speed-up vs sliding-window recomputation. — [arXiv abs](https://arxiv.org/abs/2309.17453)

- **When Attention Sink Emerges in Language Models: An Empirical View** — Xiangming Gu, Tianyu Pang, Chao Du, Qian Liu, Fengzhuo Zhang, Cunxiao Du, Ye Wang, Min Lin — ICLR 2025 (Spotlight). *Quantity (verbatim):* Sink_k^ε = (1/L)Σ_l (1/H)Σ_h 1(α_k^{l,h} > ε), α_k^{l,h} = (1/(T−k+1))Σ_{i=k}^T A_{i,k}^{l,h}; ε = 0.3, T = 64, 100 sequences without BOS; "no principal way to find an optimal threshold". *Findings:* sinks exist even in Pythia-14M; emerge after enough data (vanish at 50–200M tokens); sink key has small norm but high cosine with queries, acting as a key bias; softmax Sink₁ = 18.18 % (small setup), sigmoid+normalisation 30.24 %, sigmoid / elu+1 without normalisation ≈0.44 / 0.80 %; at 1B params softmax 45.11 % vs sigmoid 2.46 % (val loss 3.07 vs 3.10). *Remedy/implication:* remove softmax normalisation (sigmoid attention) to prevent sinks. — [arXiv abs](https://arxiv.org/abs/2410.10781); [HTML v2](https://arxiv.org/html/2410.10781v2)

- **Softpick: No Attention Sink, No Massive Activations with Rectified Softmax** — Zayd M. K. Zuhri, Erland Hilman Fuadi, Alham Fikri Aji — arXiv Apr 2025 (v3). Drops sum-to-one; 0 % sink rate at 340M and 1.8B with parity on benchmarks; attention maps with many exact zeros; better under low-bit quantisation. — [arXiv HTML v3](https://arxiv.org/html/2504.20966v3)

- **Theory, Analysis, and Best Practices for Sigmoid Self-Attention** — Jason Ramapuram et al. (Apple) — arXiv Sep 2024/v2 Jan 2025. Sigmoid attention transformers are universal approximators with better regularity than softmax; stabilising large initial attention norms is crucial; the −log n bias in σ(qk/√d − log n) is from memory of the body (the abstract fetch did not show it; unverified here). — [arXiv abs](https://arxiv.org/abs/2409.04431)

**E. Sparse / alternative normalisers**

- **From Softmax to Sparsemax: A Sparse Model of Attention and Multi-Label Classification** — André F. T. Martins, Ramón F. (Well-known; not re-fetched in this session.) — [arXiv 1602.02068](https://arxiv.org/abs/1602.02068)

- **Sparse Sequence-to-Sequence Models (α-entmax)** — Ben Peters, Vlad Niculae, André F. T. Martins — ACL 2019. - **Adaptive Attention Span in Transformers** — Sainbayar Sukhbaatar et al. — ACL 2019: learns a per-head soft mask length (span) — a learned *locality* prior that bounds the support size and therefore the maximum entropy (from memory, not re-fetched; unverified). — [arXiv 1905.07799](https://arxiv.org/abs/1905.07799)

**F. Linear / kernelised attention and "dilution"**

- **The Devil in Linear Transformer** — Zhen Qin, XiaoDong Han, Weixuan Sun, Dongxu Li, Lingpeng Kong, Nick Barnes, Yiran Zhong — EMNLP 2022. Two causes of degradation in kernel-based linear transformers: unbounded gradients and "attention dilution" ("trivially distributes attention scores over long sequences" while neglecting neighbouring structure). No formal theorem of dilution vs n in the abstract. *Remedy:* TransNormer — replace scaling with normalisation; diagonal (local) attention in early layers. *Empirical:* text classification, LM, Long-Range Arena. — [arXiv abs](https://arxiv.org/abs/2210.10340)

- **FLatten Transformer: Vision Transformer using Focused Linear Attention** — Dongchen Han, Xuran Pan, Yizeng Han, Shiji Song, Gao Huang — ICCV 2023. Diagnoses linear attention via "focus ability and feature diversity"; proposes a focused mapping function (power-based sharpening; details from memory) and a rank-restoration module. (abstract only) — [arXiv abs](https://arxiv.org/abs/2308.00442)

- **The Hedgehog & the Porcupine: Expressive Linear Attentions with Softmax Mimicry** — Michael Zhang, Kush Bhatia, Hermann Kumbong, Christopher Ré — ICLR 2024. Linear attentions lack "low-entropy (or 'spiky') weights and dot-product monotonicity"; Hedgehog learns feature maps to mimic softmax (>99 % quality recovery). — [arXiv abs](https://arxiv.org/abs/2402.04347)

- **Linear Log-Normal Attention with Unbiased Concentration** — Yury Nahshan, Joseph Kampeas, Emir Haleva — ICLR 2024. - **PolaFormer: Polarity-aware Linear Attention for Vision Transformers** — Weikang Meng, Yadan Luo, Xin Li, Dongmei Jiang, Zheng Zhang — ICLR 2025. - **MHLA: Restoring Expressivity of Linear Attention via Token-Level Multi-Head** — Kewei Zhang et al. — arXiv Jan 2026. **G. Graph transformers / GAT**

- **GraphTARIF: Linear Graph Transformer with Augmented Rank and Improved Focus** — Zhaolin Hu, Kun Li, Hehe Fan, Yi Yang — arXiv Oct 2025, v2 Jan 2026. *Quantities:* PSE entropy (from PolaFormer); rank(M) ≤ min{N,d} for M = φ(Q)φ(K)ᵀ; inter-class scatter tr(S_B). *Theory:* Theorem 1 E[tr(S_B(MX))] ≤ C·r (rank r of the attention operator bounds inter-class variance); Theorem 2 composing with a low-rank smoothing operator strictly reduces expected tr(S_B); a second "Theorem 1" (§5.2) re-states PolaFormer's f′,f″>0 ⇒ lower entropy. **I. Rank / dimensionality measures**

- **The Effective Rank: A Measure of Effective Dimensionality** — Olivier Roy, Martin Vetterli — EUSIPCO 2007 (pp. 606–610). erank(A) = exp(H(p)), p_k = σ_k/Σ_j σ_j (normalised singular values, natural log, 0 log 0 = 0); 1 ≤ erank ≤ rank, upper bound iff non-zero singular values are equal; invariant to unitary transforms; subadditive for PSD matrices. — [EPFL Infoscience PDF](https://infoscience.epfl.ch/record/110188/files/RoyV07.pdf?version=1)

### Inferences
- Three independent lines (Hahn→Chiang & Cholak 2020–22; Veličković et al. 2024; Nakanishi 2025; Vasylenko et al. 2025) reach the same elementary bound; the field converged on log n logit scaling / learned length-adaptive temperature as the minimal fix, and on sparse normalisers (entmax, softpick, sigmoid) as the structural fix.
- The ICML 2023 (Zhai) and EMNLP 2025 (Hong & Lee) "entropy collapse" literature studies the opposite regime (too sharp ⇒ instability); both regimes are controlled by the same lever, the logit spread δ (= spectral norm of W_QW_Kᵀ times input norms).

## Key Question 1 — Which works give a FORMAL statement that attention becomes more uniform as n grows (softmax with bounded logits; linear attention)? State the bound.

### Takeaway
For softmax with logits in an interval of width δ, every weight obeys e^{−δ/θ}/n ≤ α_k ≤ e^{δ/θ}/n (Veličković et al. 2025, Lemma 2.1), equivalently the max weight is ≤ 1/((n−1)e^{−δ}+1) (Nakanishi 2025) and the normalised entropy H/log n → 1 (Vasylenko et al. 2025); with a finite vocabulary, dispersion is unavoidable for every head (Theorem 2.2). For linear attention no paper I found states a comparable theorem; the dilution claim is empirical (Qin et al. 2022, GraphTARIF, Hedgehog, MHLA), though the same bound follows trivially (see Inferences).

### Cited Findings
- Lemma 2.1 (softmax must disperse): with m ≤ e_k ≤ M, δ = M−m, temperature θ: (1/n)exp(−δ/θ) ≤ α_k^(n) ≤ (1/n)exp(δ/θ), so α_k^(n) = Θ(1/n); Theorem 2.2: finite vocabulary + continuous layers ⇒ ∀θ,ε ∃n: all softmax_θ(e^(n))_k < ε; Prop. 3.1 ties δ to weight spectral norms, δ ≤ 2σ_max(Q)σ_max(K)‖y‖max_i‖x_i‖ — [Veličković et al. 2025](https://arxiv.org/html/2410.01104v3)
- Upper bound on the largest softmax output: max_i softmax(z)_i ≤ 1/((n−1)e^{−(z_max−z_min)} + 1) → 0 ("attention fading"); with SSMax (base n^{s}) the top weight → 1 iff the gap to the runner-up exceeds 1/s — [Nakanishi 2025](https://arxiv.org/html/2501.19399v1)
- "Complete dispersion": for any bounded logits, H(softmax(z_1:n))/log n → 1 at any fixed temperature; α-entmax has entropy O(log s) for support s, and support O(n^β) ⇒ normalised entropy ≤ β < 1 — [Vasylenko et al. 2025](https://arxiv.org/html/2506.16640v4)
- Minimum attainable entropy grows with length for fixed weight norms: Ent(A_i) ≥ log(1+(T−1)β) + σ̄√(T(T−1))β/(1+(T−1)β), β = exp(−σ̄√(T/(T−1))), tight — [Zhai et al. 2023](https://arxiv.org/html/2303.06296v2)
- Single-position languages: classifier cross-entropy → 1 bit as length grows because attention on position 1 is "diluted"; fixed by multiplying logits by log n (Prop. 3) — [Chiang & Cholak 2022](https://aclanthology.org/2022.acl-long.527)
- Qualitative only: softmax weight on an appended token → 0 as n grows (Lemma B.1), representations of length-n and length-(n+1) inputs become arbitrarily close (Thm 4.2); "Nothing in the paper supports a 1/n decay" rate — [Barbero et al. 2024](https://arxiv.org/html/2406.04267v2)
- Linear attention: "attention dilution … trivially distributes attention scores over long sequences" (empirical) — [Qin et al. 2022](https://arxiv.org/abs/2210.10340); linear attentions lack "low-entropy (or 'spiky') weights" — [Zhang et al. 2024](https://arxiv.org/abs/2402.04347); "overly uniform attention distributions" with rank(φ(Q)φ(K)ᵀ) ≤ min{N,d} and Theorem 1 E[tr S_B(MX)] ≤ C·r — [GraphTARIF 2025](https://arxiv.org/html/2510.10631v2); "global context collapse" — [MHLA 2026](https://arxiv.org/abs/2601.07832)
- Over-smoothing with depth (not length) is formally exponential for attention-based GNNs/graph transformers (Theorem 1) — [Wu et al. NeurIPS 2023](https://arxiv.org/abs/2305.16102); and doubly exponential for pure softmax SANs (Theorem 2.3) — [Dong et al. 2021](https://arxiv.org/html/2103.03404v2)

### Inferences
- For kernelised linear attention with a non-negative feature map φ, the row weights are a_j = φ(q)ᵀφ(k_j)/Σ_i φ(q)ᵀφ(k_i). If the kernel values lie in [m, M] with m > 0 (the "bounded logits" analogue), then a_j ∈ [m/(nM), M/(nm)], so max_j a_j ≤ (M/m)/n = Θ(1/n) — the same conclusion as Lemma 2.1 but with a *polynomial* ratio M/m instead of e^{δ/θ}. Because the ratio for softmax is exponential in the logit spread (which can be pushed up by weight norms, Prop. 3.1), softmax can delay dispersion by growing δ ∝ log n, whereas elu+1/ReLU-type kernels can only grow M/m polynomially in the feature norms; this is my derivation, consistent with but not stated in the cited papers.
- Nakanishi's bound and Lemma 2.1 are equivalent up to constants (set θ = 1): max weight ≤ e^{δ}/n and ≥ 1/((n−1)e^{−δ}+1)·… ; both require δ to grow like log n to keep a constant top weight, which is exactly the log n scaling of Chiang & Cholak / SSMax / ASEntmax.

### Gaps
- No paper found with a stated theorem "linear attention entropy → log n as n → ∞" (MHLA may contain an informal argument; body not fetched).
- Hahn 2020 was not re-fetched; its exact statement should be checked before quoting.

## Key Question 2 — How is sharpness measured in practice; which measures are comparable across lengths; recommended protocol

### Takeaway
Raw row entropy is the most common measure but its maximum is log n (log i under a causal mask), so it is not comparable across lengths; normalised entropy H/log n (or exp(H)/n, the "effective support fraction") and threshold-based sink/top-k masses are the length-comparable choices, while effective rank and spectral gap capture matrix-level (not row-level) concentration.

### Cited Findings
- Row entropy, averaged over rows/heads/examples: Ent(A_i) = −Σ_j A_ij log A_ij — [Zhai et al. 2023](https://arxiv.org/html/2303.06296v2); same with maximum log N attained by uniform rows and ‖P‖_F = √N at collapse; explicit note that the sink metric is column-wise over keys while entropy is row-wise — [Hong & Lee 2025](https://aclanthology.org/anthology-files/pdf/emnlp/2025.emnlp-main.421.pdf)
- Position-dependent maximum: H_i = −Σ_{j≤i} α_ij log α_ij has maximum log i under causal masking; lower layers "closely approaching the upper bound" — [Wang et al. 2024](https://arxiv.org/html/2404.12224v2)
- Normalised attention entropy NAE = H(re-normalised weights over the i−1 preceding tokens)/log₂(i−1), explicitly "controls for the number of tokens in the previous context" — [Oh & Schuler 2022](https://par.nsf.gov/servlets/purl/10417908)
- Dispersion ratio H/log n with the thresholds "→ 1" (complete dispersion) vs "< 1" (concentration resilience) — [Vasylenko et al. 2025](https://arxiv.org/html/2506.16640v4)
- Max weight as sharpness: head "confidence" = mean max attention weight (EOS excluded) — [Voita et al. 2019](https://lena-voita.github.io/posts/acl19_heads.html); max softmax output is the quantity bounded by SSMax theory — [Nakanishi 2025](https://arxiv.org/html/2501.19399v1); "at most 10% of their attention mass on any single word" used to describe broad heads; [CLS] last-layer entropy 3.89 nats — [Clark et al. 2019](https://arxiv.org/pdf/1906.04341)
- Sink rate: fraction of (layer, head) pairs whose mean attention on key k over queries exceeds ε, ε = 0.3, T = 64, 100 sequences, no BOS; "no principal way to find an optimal threshold" — [Gu et al. 2025](https://arxiv.org/html/2410.10781v2); same metric with ε = 0.3 default and ε = 0.8 for LLaMa 3.1 (T = 64, 170 prompts) — [Barbero et al. 2025](https://arxiv.org/html/2504.02732v4)
- Entropy of attention itself (polynomial-fit input) with H > 0.5 as the trigger for re-sharpening — [Veličković et al. 2025](https://arxiv.org/html/2410.01104v3)
- Positive-sequence entropy for unnormalised kernel scores: PSE(x) = −Σ_i (x_i/s) log(x_i/s) — [PolaFormer 2025](https://arxiv.org/abs/2501.15061v2), reused by [GraphTARIF 2025](https://arxiv.org/html/2510.10631v2)
- Matrix-level: relative residual to rank-1, ‖res(X)‖_{1,∞}/‖X‖_{1,∞} — [Dong et al. 2021](https://arxiv.org/html/2103.03404v2); effective rank erank(A) = exp(H(σ/Σσ)) ∈ [1, rank] — [Roy & Vetterli 2007](https://infoscience.epfl.ch/record/110188/files/RoyV07.pdf?version=1); entropy called "a biased metric" and spectral gap "an unbiased metric" of concentration — [Nahshan et al. 2024](https://arxiv.org/abs/2311.13541v4); rank collapse ‖V − (1/n)11ᵀV‖_F vs representational collapse ‖v_n − v_{n−1}‖₂ (Prop. 3.1: the former implies the latter) — [Barbero et al. 2025](https://arxiv.org/html/2504.02732v4)
- Graph setting: per-node maximum entropy differs with degree, so raw entropies are not comparable across nodes — [DGL GAT tutorial](https://www.dgl.ai/blog/2019/02/17/gat.html)

### Inferences (recommended protocol)
- Report, per head and per query position, (1) normalised entropy Ĥ = H/log(support size), where the support size is the number of visible keys (i under causal masks, deg(v) on graphs, n for full attention); (2) effective support ratio exp(H)/support — the fraction of keys "effectively attended", which is the perplexity analogue of Ĥ and is directly interpretable (Θ(1/n) weights give ratio → constant); (3) max weight and top-k mass for a fixed k (comparable across lengths because they do not depend on n, but note the trivial lower bound 1/n and k/n); (4) sink mass on designated keys (first token / BOS / CLS) with a stated ε and a stated T, following Gu et al.; (5) for matrix-level claims, effective rank of the attention matrix *and* of the layer output, since GraphTARIF's theory bounds class separability by rank(M) and Dong et al.'s by the residual.
- Comparability across lengths requires either normalisation by log(support) (Ĥ, NAE, Vasylenko's ratio) or support-independent statistics (max, top-k, sink-ε). Raw entropy comparisons across different n (or across graph nodes of different degree) are confounded by the log n ceiling, as Wang et al.'s "approaching the upper bound" and the DGL note both imply.
- For linear/kernel attention, compute the same statistics on the implicitly normalised weights φ(q)ᵀφ(k_j)/Σ_i φ(q)ᵀφ(k_i) (= PSE when scores are positive); comparing softmax vs linear at the *same* n with normalised entropy isolates the normaliser's effect from the length effect.
- Because entropy is row-wise and sinks are column-wise (Hong & Lee), report both: a head can be low-entropy (sharp) purely because it sinks onto token 1, which is "sharpness" that carries no content — a case the ablation of ⟨bos⟩ in Barbero et al. 2025 makes concrete.

### Gaps
- I found no paper that systematically compares the measures (entropy vs effective rank vs max weight) on the same models at multiple lengths; the recommendation above is a synthesis, not a cited protocol.
- Vig & Belinkov's per-layer entropy and first-token numbers were not extracted (abstract only).

## Key Question 3 — Structural / locality priors (masks, ALiBi, RoPE decay, adaptive span) and sharpness at length

### Takeaway
Locality priors keep sharpness at length by bounding the *effective* support (ALiBi penalty ∝ distance; adaptive span; local/diagonal attention in early layers), which the dispersion bounds show is the only way to keep max weight Θ(1) without growing logits like log n; the evidence that RoPE's "long-term decay" plays this role is contested (Round and Round), and entropy/temperature fixes help NoPE but not RoPE (Wang et al. 2024).

### Cited Findings
- ALiBi adds a penalty "proportional to their distance" to attention scores, giving an "inductive bias towards recency"; 1.3B model trained at 1024 extrapolates to 2048 — [Press et al. 2022](https://arxiv.org/abs/2108.12409)
- With α-entmax, ALiBi "produces localized support with a clear cutoff", NoPE heads stay content-driven, RoPE gives "content-dependent sparse supports" that can be more fragmented; the paper's default mixes NoPE and ALiBi heads (NAPE) — [Vasylenko et al. 2025](https://arxiv.org/html/2506.16640v4)
- Temperature scaling restores NoPE length generalisation, but for RoPE "the inflection points of entropy curves remain almost unchanged" and scaling "may contribute marginally" — [Wang et al. 2024](https://arxiv.org/html/2404.12224v2)
- Representational collapse theorem requires positional encodings that decay with distance (and bounded representations); collapse "still occurs" with sinusoidal PEs in a synthetic setting — [Barbero et al. 2024](https://arxiv.org/html/2406.04267v2)
- RoPE's usefulness in Gemma 7B comes from high frequencies forming robust positional attention patterns; the decay-with-distance explanation "is unlikely" to be the core reason — [Barbero et al. 2024/25 Round and Round](https://arxiv.org/abs/2410.06205); conversely a long-term-decay property is used to derive a lower bound on the RoPE base for a target context length — [Men et al. 2024](https://arxiv.org/abs/2405.14591)
- Causal mask + depth amplifies bias toward early positions; relative PEs (decay masks, RoPE) add within-map distance decay, producing a trade-off between long-term decay and cumulative early-position importance — [Wu, Wang, Jegelka, Jadbabaie ICML 2025](https://arxiv.org/pdf/2502.01951)
- Sink prevalence grows with pre-training context length ("essentially no sink formation at a context length of 128") and the sink is used "to avoid over-mixing" — [Barbero et al. 2025](https://arxiv.org/html/2504.02732v4)
- Linear transformers: "diagonal attention that restricts each token to neighbouring tokens in early layers" as the dilution remedy — [Qin et al. 2022](https://arxiv.org/abs/2210.10340); gated local GAT branch to raise attention rank — [GraphTARIF 2025](https://arxiv.org/html/2510.10631v2)
- Adaptive attention span (learned per-head span mask) — [Sukhbaatar et al. 2019](https://arxiv.org/abs/1905.07799) (unverified in this session)

### Inferences
- Under Lemma 2.1, a distance penalty −m·|i−j| (ALiBi) makes the logit spread δ grow linearly with distance, so the effective support (keys within O(1/m) of the query) stays constant as n grows: locality priors are precisely a mechanism for keeping δ "large relative to the support" without large weights. This is the sense in which "positional bias is a sharpness mechanism"; I did not find a paper stating it in these words, but ASEntmax's "localized support with a clear cutoff" under ALiBi is direct evidence.
- The sink can be read as the degenerate locality prior: concentrating mass on one always-present key keeps the remaining distribution sharp (low effective support) regardless of n, consistent with Barbero et al.'s over-mixing account and with sink rate rising with training context length.

### Gaps
- No work found that measures normalised entropy as a function of n separately for ALiBi, RoPE and NoPE heads in the same model (Vasylenko et al. come closest, but with entmax).
- The ALiBi slope schedule and Round-and-Round's formal theorems were not re-verified from the full text.

## Key Question 4 — Entropy / rank of attention in graph transformers and graph-structured attention

### Takeaway
Graph work documents the same two failure modes: GAT attention collapsing to near-uniform over neighbours (empirical, and theoretical in the hard regime of Fountoulakis et al.), and linear graph-transformer attention being "overly uniform" and low rank (GraphTARIF, with a rank-to-separability theorem); depth-wise over-smoothing is formally exponential for any attention-based GNN or graph transformer (Wu et al. 2023), and "over-globalizing" (Xing et al. 2024) is the graph analogue of dispersion onto distant, uninformative keys.

### Cited Findings
- GraphTARIF: linear attention in graph transformers is low-rank (rank ≤ min{N,d}) and "overly uniform" (high PSE entropy); Theorem 1 E[tr(S_B(MX))] ≤ C·r; Theorem 2 low-rank smoothing strictly reduces separability; remedy = log-power sharpening + gated GAT branch; best on all six heterophilic benchmarks — [arXiv html v2](https://arxiv.org/html/2510.10631v2)
- Over-globalizing: attention "overly focuses on those distant nodes, while the near nodes, which actually contain most of the useful information, are relatively weakened" — [Xing et al. ICML 2024](https://arxiv.org/abs/2405.01102v2)
- Oversmoothing is asymptotically inevitable for attention-based GNNs including GATs and graph transformers (exponential convergence in depth, Theorem 1) — [Wu et al. NeurIPS 2023](https://arxiv.org/abs/2305.16102)
- GAT attention coefficients near-uniform: "most of the attention coefficients are going to have uniform weights" (hard regime) — [Fountoulakis et al. JMLR 2023](https://object.cloud.sdsc.edu/v1/AUTH_da4962d3368042ac8337e2dfdd3e7bf3/ml-papers-txt/JMLR/2023/graph_attention_retrospective__072abd0f.txt); "tendency to produce uniform attention weights to all connected neighbors at every node" on unweighted graphs — [arXiv 1811.00181](https://arxiv.org/pdf/1811.00181); entropy histograms "near uniform, regardless of the heads and layers" on citation networks — [RLGM 2019 workshop paper 62](https://rlgm.github.io/papers/62.pdf) (title unverified)
- Per-node entropy maximum = log(degree), so entropies must be normalised per node — [DGL GAT blog](https://www.dgl.ai/blog/2019/02/17/gat.html)
- Over-smoothing in BERT analysed through the graph lens (attention = normalised adjacency), LayerNorm std as the driver — [Shi et al. ICLR 2022](https://arxiv.org/abs/2202.08625)

### Inferences
- GraphTARIF's diagnosis is the graph instance of KQ1: with non-negative kernels the implicit weights are Θ(1/N) over the whole node set, so a linear graph transformer on a large graph is near-uniform by construction unless (a) the feature map sharpens (power/log-power functions) or (b) a local branch re-injects a bounded-support term; its Theorem 1 gives the only formal link I found between attention *rank* and downstream separability.
- For GAT the relevant support is the neighbourhood, so "uniform attention" there means GAT ≈ GCN (Fountoulakis et al.), a milder failure than global dispersion; the correct normalised metric is H_v/log deg(v).

### Gaps
- No paper found that measures normalised attention entropy of a *softmax* graph transformer as a function of graph size N (the direct graph analogue of the length-dispersion experiments).
- GraphTARIF contains no theorem relating entropy to rank; that link remains empirical.
