# Graph structure inside the kernel feature map φ of linear attention (φ(Q)φ(K)ᵀ) — catalogue, follow-ups 2021–2026, and the LM-fusion verdict

Scope note: this file covers the line of work where attention is computed as a low-rank / kernelized product φ(Q)φ(K)ᵀ (Performer-style, "linear attention") and graph structure is injected either (a) *inside* φ (graph random features / tensor product of softmax-kernel features and graph-kernel features / structure concatenated into the kernel input), (b) *before* φ as positional/structural encodings on q,k, (c) *outside* φ as an additive sparse term, regularizer or parallel GNN branch, or (d) as a mask/multiplicative prior on quadratic softmax attention. All facts below are tied to a fetched URL; anything I could not open is flagged "unverified". Research date: 2026-11-02.

Taxonomy codes used throughout:
- **[IN-φ]** structure enters the kernel feature map itself (graph kernel features ⊗ softmax features, or structure concatenated into the kernel argument).
- **[PRE-φ]** structure enters only as input encodings (LapPE/RWSE/RoPE-type rotations) applied to q,k before a standard φ.
- **[OUT-φ]** structure enters outside the kernel: additive sparse term on observed edges, edge regularizer, parallel GCN/MPNN branch, or local-attention module.
- **[MASK-SOFTMAX]** structure as multiplicative/additive mask or bias on quadratic softmax attention (not a feature map).

## Key Question 1 — Verification and detail of the core papers (GKAT, block-Toeplitz/ICML 2022, Taming graph kernels, GRFs, NodeFormer, DIFFormer, SGFormer, Polynormer, GraphiT, GCKN, GraphGPS Performer/BigBird, Specformer, topological masking)

### Takeaway
Only three papers genuinely put *graph structure inside φ*: GKAT (2021), its ICML 2022 successor (masked low-rank attention framework), and "Linear Transformer Topological Masking with Graph Random Features" (ICLR 2025); KDLGT (IJCAI 2023) is a fourth, weaker instance (low-rank RPE concatenated into the kernel argument). NodeFormer / DIFFormer / SGFormer / Polynormer are linear-attention graph transformers whose kernel is *structure-free*; structure enters only outside φ (additive edge term, regularizer, GCN branch, local module). GraphiT and GCKN use a graph kernel as a multiplicative prior on quadratic softmax attention or as input features, not in a linear feature map.

### Cited Findings

**A. Graph Kernel Attention Transformers (GKAT) — arXiv v1, July 2021 [IN-φ]**
- v1 title "Graph Kernel Attention Transformers"; authors Krzysztof Choromanski, Han Lin, Haoxian Chen, Jack Parker-Holder; submitted 16 Jul 2021 — [arXiv 2107.07999v1](https://arxiv.org/abs/2107.07999v1)
- The same arXiv identifier was retitled; the current version (v8, 28 Mar 2023) is "From block-Toeplitz matrices to differential equations on graphs: towards a general theory for scalable masked Transformers", authors Choromanski, Lin, Chen, Zhang, Sehanobish, Likhosherstov, Parker-Holder, Sarlos, Weller, Weingarten; version history v1 16 Jul 2021 … v8 28 Mar 2023 — [arXiv 2107.07999](https://arxiv.org/abs/2107.07999)
- Mechanism (from the v1 PDF text): attention densified as A_i(k,l) = K(q_k,k_l)·T(k,l) / Σ_r K(q_k,k_r)T(k,r), where K is a kernel on feature vectors (e.g., softmax kernel exp(xyᵀ)) and T is a kernel on graph nodes depending only on topology — [arXiv 2107.07999v1 PDF, Sec. 4.1, Eq. 2](https://arxiv.org/pdf/2107.07999v1)
- Tensor-product feature map (Eq. 3): "K_prod(k,l) = E[(φ_K(q_k) ⊗ φ_T(k))(φ_K(k_l) ⊗ φ_T(l))ᵀ]" with φ_K: Rᵈ→R^{m1}, φ_T: V→R^{m2}, "u ⊗ v defines row-vectorized cartesian product"; described as "a standard finite cartesian features mechanism for the compositional kernels" — [arXiv 2107.07999v1 PDF, Sec. 4.2](https://arxiv.org/pdf/2107.07999v1)
- Graph kernel used: Random Walks Graph-Nodes Kernel (RWGNK): K(k,l) = normalized dot product of expected frequency vectors f_h^{ω(h),λ} ∈ R^N recording discounted (λ^length) visits of random walks started at k and l; expectations replaced by Monte-Carlo over "few random walks", stored as weighted lookup tables; an "anchor-points variant" indexes frequency vectors by s random anchor nodes (vectors in R^s) — [arXiv 2107.07999v1 PDF, Sec. 4.3, Eq. 4](https://arxiv.org/pdf/2107.07999v1)
- Complexity (Sec. 4.4): random walks cost O(Nτt) one-time (τ = avg walk length, t walks/node); memory O(Nm) for lookup tables (m = avg nodes visited, m ≤ τt); attention time O(N·m·r·d) and space O(Nmr + Nd + mrd), r = number of features linearizing K, d = embedding dim; "if τ, t, m, r are small constants, space and time complexity is effectively linear instead of quadratic in N" — [arXiv 2107.07999v1 PDF](https://arxiv.org/pdf/2107.07999v1)
- "Graphot": the pair S = ((K′)ᵀV, (K′)ᵀ1_N) whose sizes "do not explicitly depend on the number of graph nodes N" — a graph sketch — [arXiv 2107.07999v1 PDF, Sec. 4.5](https://arxiv.org/pdf/2107.07999v1)
- Structure type: given input graph (random walks on the observed adjacency). No text / language model anywhere; datasets: synthetic ER graphs with motifs, induced-cycle detection, bioinformatics (D&D, NCI1, PROTEINS, ENZYMES), social (IMDB-B/M, REDDIT-B/5K, COLLAB), citation networks in appendix — [arXiv 2107.07999v1 PDF, Sec. 5](https://arxiv.org/pdf/2107.07999v1)
- Results (Table 1, accuracy): D&D GKAT 78.6±3.4 vs baseline 78.4±4.5; NCI1 75.2±2.4 vs DGCNN 76.4±1.7; PROTEINS 75.8±3.8 vs baseline 75.8±3.7; ENZYMES 69.7±6.0 vs baseline 65.2±6.4 — [arXiv 2107.07999v1 PDF, Table 1](https://arxiv.org/pdf/2107.07999v1)
- Results (Table 2): IMDB-B 71.4±2.6; IMDB-M 47.5±4.5 (RWNN 47.8); REDDIT-B 89.3±2.3 (RWNN 90.4); REDDIT-5K 55.3±1.6 (DiffPool 53.8); COLLAB 73.1±2.0 (GraphSAGE 73.9) — [arXiv 2107.07999v1 PDF, Table 2](https://arxiv.org/pdf/2107.07999v1)
- Motif detection: GKAT with walk length τ=3 "outperforms all other methods for all the motifs" vs GAT/GCN/SGC; induced-cycle detection with a two-layer GKAT (τ=6) beats GCN/GAT/SGC of up to six layers; Table 4: Induced Cycle GKAT 83.6% vs GAT 77.0%, GCN 63.2%, SGC 56.6% — [arXiv 2107.07999v1 PDF, Sec. 5.1](https://arxiv.org/pdf/2107.07999v1); numbers also in [ar5iv 2107.07999](https://ar5iv.labs.arxiv.org/html/2107.07999)
- Efficiency vs GAT per attention layer (Table 3): graphot/graph size 0.54–0.55 on bio datasets, 0.18 on Citeseer, 0.07 on Pubmed; train speedup 1.40–1.42× (bio), 5.10× Citeseer, 9.50× Pubmed; inference speedup up to 9.54× — [arXiv 2107.07999v1 PDF, Table 3](https://arxiv.org/pdf/2107.07999v1)
- Ablation softmax vs linear: the paper reports accuracy loss of the random-feature GKAT vs brute-force GKAT-0 as "under 0.1%" on citation networks — [ar5iv 2107.07999](https://ar5iv.labs.arxiv.org/html/2107.07999)

**B. From block-Toeplitz matrices to differential equations on graphs (ICML 2022) [IN-φ / general masked low-rank attention]**
- Venue: Proceedings of ICML 2022, PMLR 162:3962–3983; PDF https://proceedings.mlr.press/v162/choromanski22a/choromanski22a.pdf — [PMLR](https://proceedings.mlr.press/v162/choromanski22a.html)
- Abstract: "first comprehensive approach for incorporating various masking mechanisms into Transformers architectures in a scalable way"; linear causal attention and log-linear RPE-attention (Luo et al. 2021) are special cases; casting the problem as "topological (graph-based) modulation of unmasked attention" yields "efficient d-dimensional RPE-masking and graph-kernel masking" — [arXiv 2107.07999](https://arxiv.org/abs/2107.07999)
- Framework: masked attention A = M ⊙ 𝒦(Q,K) with low-rank 𝒦 ≈ E[φ(x)ᵀφ(y)]; Lemma 3.1: if mask M supports matrix-vector products in time T_M(L), masked low-rank attention runs in O((T_M(L)+L)md) — [ar5iv 2107.07999](https://ar5iv.labs.arxiv.org/html/2107.07999)
- Specific results: causal mask O(L) via prefix sums; d-level block-Toeplitz RPE masks via FFT in O(L log L); shortest-path masks on unweighted grids tractable for any f; forests with f(z)=exp(τ(z)) in linear time; unweighted trees O(L log² L) or O(L·diam); low-rank masks M = E[M₁M₂] in O(Lr) — [ar5iv 2107.07999](https://ar5iv.labs.arxiv.org/html/2107.07999)
- Graph diffusion kernel masking: heat kernel exp(−λT), Theorem 4.1 gives Õ((|E|+L) log(2+‖A‖_F) md) via matrix-exponential action (sub-quadratic when |E| = o(L²)); hypercubes closed form ∝ (tanh λ)^dist gives block-Toeplitz O(Lmd log L); RWGNK proxy "low-rank in expectation", bounded between discounted walk-count matrices (Theorem 4.2) — [ar5iv 2107.07999](https://ar5iv.labs.arxiv.org/html/2107.07999)
- Experiments: ImageNet ViT with 2-level block-Toeplitz masking added to regular Performers (x², ELU+1, ReLU kernels) "+2.5–3.4 percentage point" gains (Figure 8) at log(L) extra cost; plus the GKAT motif/cycle/bioinformatics/social experiments carried over. No text/language-model experiments — [ar5iv 2107.07999](https://ar5iv.labs.arxiv.org/html/2107.07999)

**C. Taming graph kernels with random features (ICML 2023) [GRF foundation, not attention]**
- arXiv 2305.00156, submitted 29 Apr 2023; the arXiv page lists Krzysztof Choromanski (further ICML co-authors not visible on the landing page) — [arXiv 2305.00156](https://arxiv.org/abs/2305.00156); Semantic Scholar venue field: International Conference on Machine Learning 2023 — [Semantic Scholar API citations record, retrieved 2026-11-02](https://api.semanticscholar.org/graph/v1/paper/arXiv:2305.00156/citations)
- Introduces graph random features (GRFs): unbiased randomized estimators of kernels on graph nodes (main example the regularized Laplacian kernel) to escape "cubic (in the number of the nodes of the graph) time complexity"; includes a distributed variant and a quasi-Monte-Carlo variant q-GRFs using reinforced random walks to reduce variance; evaluation: speed, Frobenius relative error, k-means graph clustering — [arXiv 2305.00156](https://arxiv.org/abs/2305.00156)

**D. Quasi-Monte Carlo Graph Random Features (NeurIPS 2023), General/Universal Graph Random Features (ICLR 2024), Repelling Random Walks (ICLR 2024)**
- q-GRFs: Reid, Choromanski, Weller; arXiv 2305.12470 (21 May 2023); antithetic termination induces negative correlation between walk lengths and gives "lower-variance estimators of the 2-regularised Laplacian kernel under mild conditions" for any graph topology; new application: time-efficient approximation of graph diffusion — [arXiv 2305.12470](https://arxiv.org/abs/2305.12470); venue NeurIPS 2023 per [Semantic Scholar record](https://api.semanticscholar.org/graph/v1/paper/arXiv:2305.00156/citations)
- "General Graph Random Features" (the assignment's "Universal graph random features"): Reid, Choromanski, Berger, Weller; arXiv 2310.04859 (v1 7 Oct 2023, v3 24 May 2024); u-GRFs estimate arbitrary functions of a weighted adjacency matrix via random walks with a length-dependent modulation function that can be parameterized by a neural network (kernel learning); "subquadratic time complexity with respect to the number of nodes" vs cubic exact; experiments: pointwise kernel estimation, non-homogeneous graph ODEs, node clustering, kernel regression on triangular meshes; no Transformer or LM usage — [arXiv 2310.04859](https://arxiv.org/abs/2310.04859); venue ICLR 2024 per [Semantic Scholar record](https://api.semanticscholar.org/graph/v1/paper/arXiv:2305.00156/citations)
- Repelling Random Walks: Reid, Berger, Choromanski, Weller; arXiv 2310.04854 (v1 7 Oct 2023, v2 24 May 2024); correlates walker directions so estimators stay unbiased with better concentration; applications: graph kernels, PageRank, graphlet concentrations — [arXiv 2310.04854](https://arxiv.org/abs/2310.04854); the PDF header reads "Published as a conference paper at ICLR 2024" — [arXiv PDF 2310.04854](https://arxiv.org/pdf/2310.04854)

**E. Linear Transformer Topological Masking with Graph Random Features (ICLR 2025) [IN-φ]**
- Authors (15): Isaac Reid, Kumar Avinava Dubey, Deepali Jain, Will Whitney, Amr Ahmed, Joshua Ainslie, Alex Bewley, Mithun Jacob, Aranyak Mehta, David Rendleman, Connor Schenck, Richard E. Turner, René Wagner, Adrian Weller, Krzysztof Choromanski; arXiv 2410.03462 v1 4 Oct 2024, v2 15 Oct 2024 — [arXiv 2410.03462](https://arxiv.org/abs/2410.03462); ICLR 2025 poster — [ICLR 2025](https://iclr.cc/virtual/2025/poster/30895)
- Mechanism: mask M_α(G) = Σ_k α_k W^k (power series in weighted adjacency); with α_k as a convolution of coefficients f_k, M_α = Φ_G Φ_Gᵀ where Φ_G = Σ_k f_k W^k, giving per-node graph feature φ_G(v_i); each node's q/k feature φ(·) is combined with its graph feature by a Kronecker (outer) product and vectorised, so the dot product equals K_LR ⊙ M; dense graph-feature dimension is m·N (m = q/k feature size), and GRFs replace the dense graph features with sparse Monte-Carlo estimates so the combined features are sparse — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Complexity: O(N) time and memory in tokens vs O(N²) softmax and O(N log N) for the prior Toeplitz/FFT approach; the O(N) claim assumes the constant c stays fixed (bounded degree / edge weights); per-node GRF nonzeros bounded independent of N (Lemma 3.2); sparse products O(Nmd) — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Theory: Theorem 3.1 concentration bound Pr(|M̂_ij − M_ij| > t) ≤ 2 exp(−t² n³ / (2(2n−1)² c⁴)) via McDiarmid, exponential in the number of walkers n and independent of graph size when c is fixed; c grows with max|W_ij| d_i/(1−p_halt) so longer walks (small p_halt) increase c — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Mask is learnable through the coefficients α_k / f_k (not via a neural network) — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Experiments (ViT; ImageNet / iNaturalist2021 / Places365 accuracy): softmax 0.741/0.699/0.567; Toeplitz-masked linear 0.733/0.674/0.550; exact M_α-masked linear (O(N²)) 0.741/0.692/0.551; unmasked linear 0.693/0.667/0.543; GRF-masked linear 0.730/0.689/0.548 (gains over unmasked linear +3.7/+2.2/+0.5 points); feature map φ = ReLU for all ViT runs — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Ablations (Table 3, ViT, n=100 walkers, p_halt=0.5): GRF-masked 0.730; unmasked 0.693; "ad-hoc" mask without edge-weight/importance reweighting 0.689 (worse than unmasked); fully learnable dense N-dimensional graph feature (O(N²)) 0.696; more walkers reduce mask variance and improve accuracy at the cost of sparsity — [arXiv HTML 2410.03462v2 (appendix)](https://arxiv.org/html/2410.03462v2)
- Point clouds: HD-VPD robotics simulator, N = 32,768 particles, Interlacer (PCT) architecture, kNN graph k=3 rebuilt each timestep, 27 repelling random walks + 3 deterministic hops per node, asymmetric GRFs; GRF Interlacer beats vanilla transformer and message-passing Interlacer on SSIM over rollouts (figure only); ViViT Kinetics-400: softmax 0.754 vs softmax+GRFs 0.758 — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- No text or pretrained language model anywhere; GKAT is not cited by name — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)

**F. NodeFormer (NeurIPS 2022) [OUT-φ; learned latent graph + given graph as additive term]**
- Wu, Zhao, Li, Wipf, Yan; arXiv 2306.08385, comments "Published in NeurIPS 2022" — [arXiv 2306.08385](https://arxiv.org/abs/2306.08385)
- Kernelized Gumbel-Softmax message passing with Performer positive random features φ(x) = exp(−‖x‖²/2)/√m·[exp(w₁ᵀx),…,exp(w_mᵀx)], w_k ~ N(0,I); update z_u ≈ φ(q_u/√τ)ᵀ Σ_v e^{g_v/τ} φ(k_v/√τ) v_vᵀ / normalizer with Gumbel noise g and τ=0.25; shared sums give O(N) per layer — [arXiv HTML 2306.08385v1](https://arxiv.org/html/2306.08385v1)
- Relational bias: ã_uv ← ã_uv + 𝟙[a_uv=1]·σ(b^(l)) with learnable scalar b; implemented (Eq. 8) as a separate additive term after aggregation, z_u ← z_u + Σ_{v:a_uv=1} σ(b^(l)) v_v, cost O(N+E) — i.e., outside the random-feature kernel — [arXiv HTML 2306.08385v1](https://arxiv.org/html/2306.08385v1)
- Edge-level regularization: L_e = −(1/(NL)) Σ_l Σ_{(u,v)∈E} (1/d_u) log π_uv^(l), where π_uv = φ(W_Q z_u)ᵀφ(W_K z_v)/[φ(W_Q z_u)ᵀ Σ_w φ(W_K z_w)]; O(E) after one O(N) summation; total loss L_s + λL_e — [arXiv HTML 2306.08385v1](https://arxiv.org/html/2306.08385v1)
- Datasets: Cora, Citeseer, Deezer, Actor (2K–20K nodes), OGB-Proteins (>0.1M), Amazon2M (>2M), Mini-ImageNet, 20News-Groups (~10K texts, features "extracted by TF-IDF" — text as bag-of-words, no pretrained LM) — [arXiv HTML 2306.08385v1](https://arxiv.org/html/2306.08385v1)
- Results: OGB-Proteins ROC-AUC 77.45±1.15 (3.2 GB) vs GraphSAINT-GAT 74.63, GCN 72.51; Amazon2M 87.85±0.24 (4.0 GB) vs GCN 83.90 (5.7 GB); deterministic-softmax variants score lower (75.50/76.18 on Proteins; 87.02/87.55 on Amazon2M) — [arXiv HTML 2306.08385v1](https://arxiv.org/html/2306.08385v1)
- Ablation (Table 6): Cora full 88.69±0.46 / w/o edge reg 81.98±0.46 / w/o relational bias 88.06±0.59; Citeseer 76.33 / 70.60 / 74.12; Deezer 71.24 / 71.22 / 71.10; Actor 35.31 / 35.15 / 34.60 — [arXiv HTML 2306.08385v1 (appendix)](https://arxiv.org/html/2306.08385v1)

**G. DIFFormer (ICLR 2023 spotlight) [OUT-φ; latent all-pair diffusion + optional given graph]**
- Wu, Yang, Zhao, He, Wipf, Yan; arXiv 2301.09474; comments: ICLR 2023 spotlight — [arXiv 2301.09474](https://arxiv.org/abs/2301.09474)
- DIFFormer-s: L2-normalized q,k and linear kernel ω_ij = 1 + (z_i/‖z_i‖)ᵀ(z_j/‖z_j‖), computed as P = R[1(1ᵀV) + Q̃(K̃ᵀV)], O(NKd²) overall; DIFFormer-a: Sigmoid(QKᵀ) explicit N×N, O(N²Kd²) — [ar5iv 2301.09474](https://ar5iv.labs.arxiv.org/html/2301.09474)

**I. Polynormer (ICLR 2024) [OUT-φ; local GAT-style module then structure-free global sigmoid-kernel attention]**

**J. GraphiT (2021) [MASK-SOFTMAX; diffusion kernel as multiplicative prior; GCKN features into inputs]**
- Mialon, Chen, Selosse, Mairal; arXiv 2106.05667 (10 Jun 2021); code github.com/inria-thoth/GraphiT; no venue on arXiv page — [arXiv 2106.05667](https://arxiv.org/abs/2106.05667)
- Attention: normalize(exp(QQᵀ/√d_out) ⊙ K_r)V with row-wise ℓ1 normalization (kernel multiplied into the numerator; shared Q=K to keep K_r symmetric PD); kernels: diffusion K_D = e^{−βL} (β=1.0), p-step random walk (I−γL)^p (γ=0.5), adjacency (1-step, γ=1); GCKN substructure features (paths up to length 5, or 8 on ZINC) concatenated to node inputs; attention cost "scales quadratically"; no linear/kernelized variant implemented — [ar5iv 2106.05667](https://ar5iv.labs.arxiv.org/html/2106.05667)

**N. KDLGT (IJCAI 2023) [IN-φ, weak form: low-rank RPE concatenated into the kernel argument]**
- Wu, Xu, Zhu, Song, Lin, Wang, Liu (Peking Univ., Alibaba); IJCAI-23 pp. 2370–2378 — [IJCAI 2023/263 PDF](https://www.ijcai.org/proceedings/2023/0263.pdf)
- Mechanism: with A = exp(QKᵀ + B) for an RPE matrix B, (i) "multiplication decomposition" B = B_q B_kᵀ (d′ ≪ N): QKᵀ + B = [Q, B_q][K, B_k]ᵀ, then Performer kernel decomposition exp(QKᵀ) ≈ φ(Q)φ(K)ᵀ on the concatenated vectors, complexity O(N(d+d′)r); (ii) "addition decomposition" B_ij = b_i + b_j: [Q, b, 1][K, 1, b]ᵀ, O(N(d+2)r); (iii) "ineffective" high-rank B such as shortest-path distance, replaced by Shortest Anchor Path Distance d_a(v_i,v_j) = ½d(v_i,a) + ½d(a,v_j) with K anchor nodes (k-dominant set), O(NK(d+2)r) — [IJCAI 2023/263 PDF, Sec. 4](https://www.ijcai.org/proceedings/2023/0263.pdf)
- Models: LSAT (linearized Structure-Aware Transformer, whose RPE is κ(φ(v_i,G), φ(v_j,G)) from k-subtree/k-subgraph GNN extractors) and SAPDGT (Graphormer-like with anchor distances); theoretical bound on the gap vs exact softmax GT in terms of c_max; speedup "9.63x" for LSAT vs SAT at certain graph sizes; OOM for softmax SAT beyond N > 2¹⁴ — [IJCAI 2023/263 PDF](https://www.ijcai.org/proceedings/2023/0263.pdf)
- Results (Table 2): ZINC MAE SAT 0.082 / LSAT 0.130 / GPS(GNN+RWSE) 0.070; OGBG-MOLHIV SAT 79.54 / LSAT 78.98; NCI1 SAT 81.69 / LSAT 81.33 / SAPDGT 81.99 / GKAT 75.20; Cora SAT 83.06 / LSAT 83.37 / GKAT 73.84; PubMed SAT 89.19 / LSAT 89.03 / GKAT 72.31 / Graphormer OOM — [IJCAI 2023/263 PDF, Table 2](https://www.ijcai.org/proceedings/2023/0263.pdf)

### Inferences
- The "structure-in-φ" idea has a single continuous lineage (Choromanski/Reid group): GKAT 2021 (RWGNK ⊗ softmax features) → ICML 2022 general masked low-rank theory → GRF theory 2023–2024 → ICLR 2025 topological masking (GRF ⊗ q/k features with concentration bounds). Everything else in the "linear graph transformer" literature keeps φ structure-free and bolts structure on outside.
- GKAT's own numbers were modest (best on 3/4 bio datasets, top-2 on 4/5 social); KDLGT's Table 2 shows GKAT well below SAT/LSAT on Cora/PubMed/NCI1, which is consistent with the field moving away from RWGNK-in-φ toward PE-on-inputs or GCN-branch designs.
- The ICLR 2025 result (GRF mask recovers most of the gap between unmasked linear 0.693 and softmax 0.741 on ImageNet, reaching 0.730) is the strongest quantitative evidence that structure-in-φ matters for linear attention; but all its graphs are grids or kNN graphs, not arbitrary graphs, and no text appears.

## Key Question 2 — 2024–2026 extensions of graph random features and of structure-aware kernelized / linear-time graph attention (cited-by enumeration)

### Takeaway
GRFs have an active 2024–2026 follow-up stream (QMC/variance work, GRFs++, GRF Gaussian processes, SWING, manifold random features, random-wavelet features), but the only follow-up that puts GRFs *into attention* is the ICLR 2025 topological-masking paper. The 2024–2026 linear-time graph transformers (Polynormer, GraphTARIF, DUALFormer, G2LFormer, GT-SNT, etc.) keep φ structure-free; the 2025–2026 RoPE-for-graphs line (WIRE, AW-RoPE) is the new way to make structure *compatible* with linear attention, but it enters before φ (rotation of q,k), not inside φ.

## Key Question 3 — Has any paper used structure-aware linear / kernelized attention to connect a pretrained language model's token sequence with a graph?

### Takeaway
No. Across every paper opened and every search run, I found **no paper** that fuses a pretrained language model's token sequence with a graph (code AST, molecular graph, knowledge graph, text-attributed graph) through a *structure-aware linear/kernelized* attention (graph kernel or GRF inside φ, or even structure-on-inputs + Performer). The nearest work either (a) uses structure-aware *softmax* attention with additive bias/mask inside a pretrained LM (GIMLET/T5, UTGDiff, DuConTE, Graph-KV, UniGTE, GL-Fusion), or (b) uses linear attention with graphs but no text/LM (GKAT, topological masking, NodeFormer, etc.), or (c) uses linear attention on text/SMILES without graph structure (MoLFormer).

## Key Question 4 — Matched comparisons: structure inside φ vs additive bias with softmax vs mask

### Takeaway
No paper runs a clean three-way, parameter-matched comparison of {structure-in-φ, additive-bias softmax, hard mask}. The best partial evidence is the ICLR 2025 ViT table (unmasked linear vs GRF-in-φ vs exact mask vs Toeplitz mask vs softmax), GraphGPS/Exphormer tables (full softmax vs Performer vs BigBird vs expander-sparse mask under identical GPS recipes), GraphiT's kernel-prior ablation, and NodeFormer's additive-bias/regularizer ablation.

### Cited Findings
- Structure-in-φ vs no structure vs exact mask (same linear ViT, ReLU φ): ImageNet unmasked linear 0.693 → GRF-in-φ 0.730 → exact O(N²) mask 0.741 = softmax 0.741; a dense learnable N-dim graph feature of the same O(N²) cost reaches only 0.696; an ad-hoc GRF without importance weights 0.689 — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Block-Toeplitz (RPE) mask inside Performer attention on ImageNet: +2.5–3.4 points over unmasked Performers at a log(L) cost factor — [ar5iv 2107.07999](https://ar5iv.labs.arxiv.org/html/2107.07999)
- Softmax vs Performer vs BigBird vs sparse-mask (Exphormer) under identical GraphGPS recipes: CIFAR10 72.305 / 70.670 / 70.480 / 74.69; MalNet-Tiny 93.50 / 92.64 / 92.34 / 94.02; PascalVOC-SP F1 0.3736 / 0.3724 / 0.2762 / 0.3975; Peptides-Func AP 0.6535 / 0.6475 / 0.5854 / 0.6527 — [arXiv HTML 2303.06147v2](https://arxiv.org/html/2303.06147v2); GraphGPS's own table: PCQM4Mv2 MAE Transformer 0.1159 vs Performer 0.1142 vs BigBird 0.1237 — [ar5iv 2205.12454](https://ar5iv.labs.arxiv.org/html/2205.12454)
- Multiplicative kernel prior on softmax (GraphiT): NCI1 70.0 (vanilla) → 79.7 (adjacency) / 78.9 (diffusion); ZINC MAE 0.696 → 0.243 / 0.255; on PROTEINS and PTC the prior can hurt (75.6 → 72.4 with adjacency on PROTEINS) — [ar5iv 2106.05667](https://ar5iv.labs.arxiv.org/html/2106.05667)
- Additive sparse term outside φ (NodeFormer relational bias) vs edge regularizer: removing the regularizer costs 6.7 points on Cora and 5.7 on Citeseer, removing the relational bias costs 0.6 and 2.2 — [arXiv HTML 2306.08385v1](https://arxiv.org/html/2306.08385v1)
- Linear kernel with vs without local-GNN value branch (GraphTARIF): Minesweeper 91.62 → 99.03; Roman-Empire 89.39 → 93.23 — [arXiv HTML 2510.10631v2](https://arxiv.org/html/2510.10631v2)
- Linearizing a structure-aware softmax GT (KDLGT): LSAT vs SAT ZINC 0.130 vs 0.082, MOLHIV 78.98 vs 79.54, NCI1 81.33 vs 81.69, Cora 83.37 vs 83.06 — structure retained inside the kernel argument costs little on node tasks, more on ZINC — [IJCAI 2023/263 PDF](https://www.ijcai.org/proceedings/2023/0263.pdf)
- TokenGT: same structure encodings (LapPE identifiers) under softmax vs Performer: 0.0910 vs 0.0935 valid MAE on PCQM4Mv2 at 48.5M params — [arXiv HTML 2207.02505v2](https://arxiv.org/html/2207.02505v2)
- GKAT vs GAT at matched parameter budgets (242 trainable params on induced-cycle detection) favors GKAT: 83.6% vs 77.0% — [arXiv 2107.07999v1 PDF](https://arxiv.org/pdf/2107.07999v1)

### Inferences
- Where a comparison exists, structure-in-φ recovers roughly 75–80% of the gap between structure-free linear attention and softmax/exact-mask attention on grid graphs (ICLR 2025), while structure-as-sparse-mask (Exphormer) can even beat full softmax on graph benchmarks — suggesting that for small/medium graphs the mask route is the stronger baseline and φ-injection pays off mainly when N is large (>30k tokens) and quadratic masks are unaffordable.
- No evidence yet exists for arbitrary (non-grid, non-kNN) graphs that GRF-in-φ matches an additive-bias softmax GT at equal parameters; GKAT's numbers against KDLGT/SAT suggest it does not.

### Gaps
- No paper matches parameters across {in-φ, bias, mask} on the same graph benchmark; all comparisons above are within one axis.
- The ICLR 2025 paper does not compare against softmax-with-exact-mask (only linear-with-exact-mask).

## Key Question 5 — Cost of tensor-product feature maps (d_s × d_g) and variance of graph random features on sparse graphs; mitigations

### Takeaway
The tensor product multiplies feature width (GKAT: O(N·m·r·d) time, O(Nmr) memory with m = graph-feature support and r = softmax features; ICLR 2025: dense width m·N, made tractable only because GRFs are sparse with per-node nonzeros bounded independent of N). Variance of GRFs grows with walk length (small p_halt) and the constant c ∝ max|W_ij|d_i/(1−p_halt); on sparse / high-diameter graphs regular GRFs return exactly zero for node pairs whose walks never meet. Mitigations proposed: more walkers, importance sampling, antithetic termination (q-GRFs), repelling walks, variance-reducing couplings, walk stitching with Poisson halting (GRFs++), and asymmetric GRFs (cheaper but believed higher-variance).

### Cited Findings
- GKAT cost: attention time O(N·m·r·d), space O(Nmr + Nd + mrd), with m ≤ τ·t (walk length × walks per node) or m = #anchor points; "also linear in m, but as long as m ≪ N, this mechanism brings computational gains" — [arXiv 2107.07999v1 PDF, Sec. 4.2/4.4](https://arxiv.org/pdf/2107.07999v1)
- ICLR 2025: dense combined feature dimension m·N (m = q/k feature size, N nodes); GRFs make the graph features sparse so the Kronecker features are sparse; Lemma 3.2 bounds per-node nonzeros in terms of n and p_halt; sparse products cost O(Nmd); experiments used n = 4 walkers, p_halt = 0.5, d = 8, m = 8 for FLOPs, p_halt = 0.1 for ViT training, n = 100 for ablations — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Variance / concentration: Theorem 3.1 bound decays as exp(−t²n³/(2(2n−1)²c⁴)); c grows as p_halt → 0; "larger n reduces mask variance and improves accuracy, while making the features less sparse and raising computational cost"; asymmetric GRFs "are believed, but not proven, to give higher-variance mask estimates" — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Importance sampling is crucial: dropping edge-weight/sampling-probability reweighting gives 0.689 (< unmasked 0.693) vs 0.730 with it — [arXiv HTML 2410.03462v2](https://arxiv.org/html/2410.03462v2)
- Sparse / large-diameter graphs: regular GRFs give kernel estimate zero for node pairs whose walks never intersect; higher halting probability shortens walks but sacrifices distant pairs; GRFs++ stitch l short walks (unbiased), use Poisson halting, and show better accuracy on distant pairs for graphs of diameter up to 159 (Peptides, CIFAR-10, Reddit-Binary) — [arXiv HTML 2510.07716v1](https://arxiv.org/html/2510.07716v1)
- q-GRFs: antithetic termination yields lower variance for the 2-regularised Laplacian kernel "for any graph topology, provided the termination probability or the graph's spectral radius is sufficiently small" — [arXiv PDF 2305.12470](https://arxiv.org/pdf/2305.12470), [arXiv 2305.12470](https://arxiv.org/abs/2305.12470)
- Repelling random walks: for transient repelling ensembles Var_repelling ≤ Var_iid on any graph; combined with antithetic termination, relative error reductions of more than 50% vs i.i.d. walks were reported — [arXiv HTML 2310.04854](https://arxiv.org/html/2310.04854)
- Diffusion-kernel q-GRFs: antithetic termination benefit depends on graph family (ER, BA, binary tree, ladder); lower variance shown on ladder graphs — [arXiv 2410.08389](https://arxiv.org/abs/2410.08389)
- Taming graph kernels: GRFs introduced precisely to avoid cubic exact kernel cost; q-GRF variant via reinforced random walks; distributed variant across machines — [arXiv 2305.00156](https://arxiv.org/abs/2305.00156)
- GKAT's anchor-points variant trades lookup tables for fixed s-dimensional frequency vectors (dense features of width s) — [arXiv 2107.07999v1 PDF, Sec. 4.3](https://arxiv.org/pdf/2107.07999v1)

### Inferences
- In practice the tensor product is only affordable because one factor is sparse (GRF support ≈ n walkers × expected walk length ≈ n/p_halt) or small (anchor points s); dense d_s × d_g features would cost d_s·N per token.
- For a sparse text-token graph (e.g., an AST or dependency graph, degree ≤ 3), GRF variance is low per edge but coverage of distant pairs collapses; GRFs++-style stitching or longer walks (with higher c) would be required, and no paper has measured this on linguistic graphs.

### Gaps
- No published variance formula specific to sparse graphs; the ICLR 2025 bound is in terms of a constant c that depends on degree and p_halt, not sparsity per se.
- No wall-clock FLOP tables for the Kronecker feature construction were found (the ICLR 2025 appendix reports only asymptotic costs).

## Key Question 6 — Adjacent but distinct: graph state-space models (Graph-Mamba, GMN)

### Takeaway
Graph-Mamba (Wang et al. 2024) and Graph Mamba Networks (Behrouz & Hashemi 2024) are linear-time alternatives that replace attention with selective SSM recurrences over graph-derived token sequences; they contain no kernel feature map and no φ(Q)φ(K)ᵀ structure, so they are outside this catalogue.

### Cited Findings
- Graph-Mamba: Chloe Wang, Oleksii Tsepa, Jun Ma, Bo Wang; arXiv 2402.00789 (1 Feb 2024); Mamba block + input-dependent node selection with graph-centric node prioritization/permutation; claims better long-range performance on ten benchmarks at a fraction of FLOPs/GPU memory — [arXiv 2402.00789](https://arxiv.org/abs/2402.00789)
- Graph Mamba Networks (GMN): Ali Behrouz, Farnoosh Hashemi; arXiv 2402.08678 (v2 19 Feb 2024); neighborhood tokenization, token ordering, bidirectional selective SSM encoder, local encoding, optional PE/SE; argues Transformers, complex message passing and SE/PE are "sufficient but not necessary" — [arXiv 2402.08678](https://arxiv.org/abs/2402.08678)
- GSSC — What Can We Learn from State Space Models for Machine Learning on Graphs? (Huang, Miao, Li; arXiv 2406.05815, v2 Oct 2024; TPAMI 2026 version per S2): SSM-style convolution with "factorizable graph kernels that rely on relative node distances"; cites Taming graph kernels; convolution not attention — [arXiv 2406.05815](https://arxiv.org/abs/2406.05815)

### Inferences
- GSSC is the closest SSM relative of the structure-in-φ idea (factorizable graph kernels as convolution kernels), but it factorizes the graph kernel alone, not a product with a feature-similarity kernel.

### Gaps
- Neither Mamba paper's landing page states a formal complexity bound or named datasets; full texts not opened.

**Final verdict.** Structure-inside-φ linear attention exists (GKAT 2021 → ICML 2022 → ICLR 2025 topological masking; KDLGT 2023 as a low-rank-RPE variant) and is well characterized theoretically (tensor-product features, O(N) with sparse GRFs, McDiarmid concentration). It has been applied only to synthetic graphs, TU benchmarks, citation graphs, image grids, point clouds and video. As of 2026-11-02, no paper found uses it — or any structure-aware kernelized attention — to fuse a pretrained language model's token sequence with a graph; the LM+graph literature uses softmax biases/masks exclusively.
