# Graph structure injected into attention components: graph transformers and structure-aware attention (2020–2026)

Component legend used throughout (from the assignment):
- **(a) score bias / relative term** — additive or multiplicative term on the Q·K logits (edge type, SPD, tree distance, diffusion kernel, resistance distance, RRWP…)
- **(b) support / masking** — which pairs may attend (neighbors only, k-hop, expander edges, DAG reachability, data-flow alignment edges…)
- **(c) normalization** — softmax vs. kernelized/linear (Performer, cosine, sigmoid) vs. Gumbel sampling vs. sparsemax/entmax
- **(d) value / output transform** — relation-conditioned W_V, edge-conditioned values, edge channels updated per layer
- **(e) positional / structural encodings** — LapPE, RWSE, degree, SVD-PE, tree/DAG PE added to tokens

Text/LM column: "none" means the paper neither uses text input nor a pretrained language model (background citations of NLP do not count). Numbers in parentheses after claims are taken from the paper text I extracted (PDF→text or arXiv HTML), with the URL given.

## Key Question 1 — Verify the starting-point papers: venue, mechanism, component(s), ablations, text/LM

### Takeaway
All 17 starting-point papers exist and were verified at primary URLs; venues are confirmed except where noted (GraphiT and "Attending to Graph Transformers" arXiv pages list no venue but the TMLR PDF header confirms the latter). Most of them modify component (a) (attention-score bias) and/or (e) (PE/SE); only a few touch (c) normalization (NodeFormer, SGFormer, DIFFormer, GraphGPS-Performer) or (d) value transform (GRIT, Relational Attention, EGT gating); none of them involve text or a pretrained language model except via TF-IDF/Word2Vec features on standard benchmarks.

### Cited Findings (catalogue, chronological)

**Self-Attention with Relative Position Representations — Shaw, Uszkoreit, Vaswani — NAACL 2018.** Components: (a)+(d): relative "edge" vectors a^K_ij added to keys and a^V_ij added to values. Domain: machine translation (WMT14). Text/LM: yes (pure NLP). Component-wise ablation: yes — on WMT14 EN-DE dev (newstest2013), a^K+a^V = 25.8 BLEU, a^K only = 25.8, a^V only = 25.3, neither = 12.5, i.e., the key-side (score) term carries essentially all of the benefit and the value-side term adds nothing on top. The abstract frames this as "relation-aware self-attention mechanisms that can generalize to arbitrary graph-labeled inputs." — [arXiv 1803.02155](https://arxiv.org/abs/1803.02155); equations/ablation from [ar5iv](https://ar5iv.labs.arxiv.org/html/1803.02155). (Included as the origin of the (a)-vs-(d) decomposition that graph papers later inherit.)

**A Generalization of Transformer Networks to Graphs — Dwivedi & Bresson — AAAI 2021 Workshop on Deep Learning on Graphs (DLG-AAAI'21).** Components: (b) neighborhood-restricted attention; (e) Laplacian eigenvector PE; also BatchNorm replaces LayerNorm and an edge-feature pipeline. Datasets: ZINC, PATTERN, CLUSTER. Ablation: full factorial over {sparse, full} × {LapPE, none} × {LN, BN}; sparse beats full in every cell (ZINC MAE 0.226 sparse+BN+LapPE vs 0.598 full; CLUSTER 73.169 vs 27.121; PATTERN 84.808 vs 54.941). Text/LM: none. — [arXiv 2012.09699](https://arxiv.org/abs/2012.09699); table from [ar5iv](https://ar5iv.labs.arxiv.org/html/2012.09699).

**Do Transformers Really Perform Bad for Graph Representation? (Graphormer) — Ying, Cai, Luo, Zheng, Ke, He, Shen, Liu — NeurIPS 2021.** Components: (a) spatial encoding = learnable scalar bias indexed by shortest-path distance; (a) edge encoding = dot-product of edge features along the shortest path with learnable embeddings, added as attention bias; (e) centrality (degree) encoding added to node features. Datasets: PCQM4M-LSC, OGBG-MolHIV/MolPCBA, ZINC. Component-wise ablation: yes (Table 5, PCQM4M-LSC valid MAE, 12-layer models): nothing 0.2276 → LapPE 0.1483 → spatial encoding 0.1427 → +centrality 0.1396 → +edge "via node" 0.1328 / "via Aggr" 0.1327 / "via attn bias" 0.1304. Authors: "centrality encoding is indispensable" and "edge encoding as attention bias is more effective". Text/LM: none. — [arXiv 2106.05234](https://arxiv.org/abs/2106.05234) (ablation extracted from the PDF at that URL).

**Rethinking Graph Transformers with Spectral Attention (SAN) — Kreuzer, Beaini, Hamilton, Létourneau, Tossou — NeurIPS 2021.** Components: (e) learned positional encoding (LPE) from the full Laplacian spectrum processed by a Transformer; (a)/(b) full-graph attention with separate parameters for real vs. virtual (non-)edges (noted by GraphGPS as "conditional attention for real and virtual edges"). Datasets: ZINC, PATTERN, CLUSTER, MolHIV/MolPCBA. Ablation: not visible on the abstract page (gap). Text/LM: none. — [arXiv 2106.03893](https://arxiv.org/abs/2106.03893); real/virtual edge description from the GraphGPS related-work section at [arXiv 2205.12454](https://arxiv.org/abs/2205.12454).

**GraphiT: Encoding Graph Structure in Transformers — Mialon, Chen, Selosse, Mairal — arXiv 2021 (no peer-reviewed venue listed on arXiv).** Components: (a) multiplicative relative PE — exponentiated logits are multiplied elementwise by a positive-definite graph kernel K_r (diffusion kernel e^{-βL}, β=1; p-step random-walk kernel (I−γL)^p; adjacency) then ℓ1 row-normalized; (e) GCKN path features concatenated to node inputs. Values receive no positional information. Datasets: MUTAG, PROTEINS, PTC, NCI1, ZINC. Component-wise ablation: yes (Table 2): ZINC MAE vanilla 0.696 → adjacency-kernel bias 0.243 → LapPE+adj 0.202 → GCKN+3-step 0.203; relative kernel bias alone gives the largest single gain on ZINC and NCI1 (70.0 → 79.7). Text/LM: none. — [arXiv 2106.05667](https://arxiv.org/abs/2106.05667); table from [ar5iv](https://ar5iv.labs.arxiv.org/html/2106.05667).

**Global Self-Attention as a Replacement for Graph Convolution (EGT) — Hussain, Zaki, Subramanian — KDD 2022.** Components: (a) edge channels e_ij added as bias to clipped Q·K logits; (d) edge channels sigmoid-gate the values before aggregation; edge channels are updated every layer from the attention logits; (e) optional SVD-based PE (rank 8, sign-flipped). Datasets: PATTERN, CLUSTER, TSP, MNIST, CIFAR10, ZINC, PCQM4M(v2), MolPCBA, MolHIV. Component-wise ablation: yes (Table 4): EGT ZINC MAE 0.108 vs EGT-Simple (no dedicated edge channels) 0.228 vs EGT-Constrained (1-hop-only attention, i.e., component (b)) 0.174 vs w/o PE 0.187; on PCQM4Mv2 0.0899 vs 0.0900 / 0.0934 / 0.0901. Table 5 (PCQM4Mv2 small): gating "significant improvement", virtual nodes and PE "more modest". Text/LM: none. — [arXiv 2108.03348](https://arxiv.org/abs/2108.03348); details from [arXiv HTML v3](https://arxiv.org/html/2108.03348v3).

**Structure-Aware Transformer for Graph Representation Learning (SAT) — Chen, O'Bray, Borgwardt — ICML 2022.** Components: the structure extractor (k-subtree = k GNN layers; k-subgraph = sum of GNN outputs over the k-hop neighborhood) is applied to node representations *before computing Q and K*; the value term stays a linear function of raw node features (so this is a structure-conditioned score, closest to (a), not (d)); (e) RWPE/LapPE optional. Datasets: ZINC, CLUSTER, PATTERN, OGBG-PPA, OGBG-CODE2. Ablation: yes — ZINC MAE Transformer+RWPE 0.310 vs k-subtree SAT 0.102 / k-subgraph SAT 0.094; absolute PE helps less than structure-aware attention (k-subgraph: none 0.097, LapPE 0.091, RWPE 0.094); k≈3 best. Text/LM: none (OGBG-CODE2 is AST graphs with token-type features, no LM). — [arXiv 2202.03036](https://arxiv.org/abs/2202.03036); details from [arXiv HTML v3](https://arxiv.org/html/2202.03036v3).

**Recipe for a General, Powerful, Scalable Graph Transformer (GraphGPS) — Rampášek, Galkin, Dwivedi, Luu, Wolf, Beaini — NeurIPS 2022.** Components: (e) PE/SE taxonomy (local/global/relative × positional/structural); hybrid layer = MPNN on real edges + global attention; (c) attention can be Transformer (softmax), Performer or BigBird. Datasets: ZINC, PATTERN, CLUSTER, MNIST, CIFAR10, OGB molhiv/molpcba/ppa/code2, PCQM4Mv2, MalNet-Tiny, LRGB. Component-wise ablation: yes (Table 2): removing MPNN is catastrophic (ZINC 0.070 → 0.217; CIFAR10 72.31 → 68.86; MalNet 93.50 → 73.90); removing global attention costs little (ZINC unchanged 0.070, PCQM4Mv2 0.1159 → 0.1213, CIFAR10 72.31 → 69.95); Performer 0.1142 PCQM4Mv2 / 70.67 CIFAR10, BigBird 0.1237 / 70.48 ("no significant gain"); PE/SE: none 0.113 ZINC vs RWSE 0.070, LapPE 0.116, SignNetDeepSets 0.079. Text/LM: none (ogbg-code2 AST only). — [arXiv 2205.12454](https://arxiv.org/abs/2205.12454) (ablation extracted from the PDF at that URL).

**Pure Transformers are Powerful Graph Learners (TokenGT) — Kim, Nguyen, Min, Cho, Lee, Lee, Hong — NeurIPS 2022.** Components: tokenization of nodes AND edges; (e) node identifiers (orthogonal random features or Laplacian eigenvectors) and type identifiers; the attention itself is unmodified (standard softmax; Performer variant). Ablation: PCQM4Mv2 valid MAE plain Transformer 0.2340 → TokenGT(ORF) 0.0962 → TokenGT(Lap) 0.0910; TokenGT(Lap)+Performer 0.0935. Text/LM: none. — [arXiv 2207.02505](https://arxiv.org/abs/2207.02505); venue confirmed at [NeurIPS 2022 proceedings](https://proceedings.neurips.cc/paper_files/paper/2022/hash/5d84236751fe6d25dc06db055a3180b0-Abstract-Conference.html); ablation numbers from [ar5iv](https://ar5iv.labs.arxiv.org/html/2207.02505).

**NodeFormer: A Scalable Graph Structure Learning Transformer for Node Classification — Wu, Zhao, Li, Wipf, Yan — NeurIPS 2022.** Components: (c) kernelized Gumbel-Softmax attention with random-feature map φ (O(N), τ=0.25, K=5 samples); (a) "relational bias" σ(b^(l)) added to attention weights of observed edges; edge-level regularizer on input topology. Datasets: Cora, Citeseer, Deezer, Actor, OGB-Proteins, Amazon2M, Mini-ImageNet, 20News-Groups. Ablation: Gumbel vs plain softmax (NodeFormer 77.45 ROC-AUC on OGB-Proteins vs softmax τ=1 "-dt" 75.50 and softmax τ=0.25 "-tp" 76.18; Amazon2M 87.85 vs 87.02 / 87.55); relational-bias/edge-loss ablation reported in Appendix Table 6 (numbers not extracted). Text/LM: 20News-Groups uses TF-IDF features; no language model. — [arXiv 2306.08385](https://arxiv.org/abs/2306.08385); details from [arXiv HTML](https://arxiv.org/html/2306.08385).

**Relational Attention: Generalizing Transformers for Graph-Structured Tasks (Relational Transformer, RT) — Diao & Loynd — ICLR 2023.** Components: (a)+(d) edge vectors enter query, key AND value: q_ij = n_i W_n^Q + e_ij W_e^Q, k_ij = n_j W_n^K + e_ij W_e^K, v_ij = n_j W_n^V + e_ij W_e^V; edge vectors updated each layer from (e_ij, e_ji, n_i, n_j). Datasets: CLRS-30 (8 core tasks for ablations), lobster-graph shortest paths, Sokoban. Ablation: set-Transformer without edges 42.34% vs RT 81.30% (Table 13); RT without edge updates 53.99% (Table 17). The paper does NOT separately ablate edge-in-Q/K vs edge-in-V, and does not compare against a Graphormer-style scalar bias. Text/LM: none. — [arXiv 2210.05062](https://arxiv.org/abs/2210.05062); equations/ablations from [arXiv HTML v3](https://arxiv.org/html/2210.05062v3).

**DIFFormer: Scalable (Graph) Transformers Induced by Energy Constrained Diffusion — Wu, Yang, Zhao, He, Wipf, Yan — ICLR 2023 (spotlight).** Components: (c) normalization/attention form derived from an energy functional: DIFFormer-s uses ω_ij = 1 + cos-sim(z_i, z_j), row-normalized (O(N)); DIFFormer-a uses sigmoid(z_i^T z_j), row-normalized (O(N²)) — neither is softmax. Datasets: Cora/Citeseer/Pubmed, large graphs, CIFAR/STL/Mini-ImageNet, 20News-Groups (text), spatio-temporal. Ablation: simple vs advanced (Cora 85.9 vs 84.1; Citeseer 73.5 vs 75.7; 20News with 1000/2000/4000 labels 57.7/61.2/65.9 vs 57.9/61.3/64.8). Text/LM: 20News-Groups with TF-IDF word features; no language model. — [arXiv 2301.09474](https://arxiv.org/abs/2301.09474); details from [arXiv HTML v4](https://arxiv.org/html/2301.09474v4).

**Rethinking the Expressive Power of GNNs via Graph Biconnectivity (Graphormer-GD) — Zhang, Luo, Wang, He — ICLR 2023 (Outstanding Paper).** Components: (a) distance injected both as additive bias φ2(D) on logits and as multiplicative term φ1(D) ⊙ softmax(·), with D = shortest-path and resistance distance; introduces the GD-WL test. Datasets: synthetic cut-vertex/cut-edge, ZINC. Ablation: Graphormer-GD 100%/100% on cut vertex/edge vs Graphormer 76.4%/84.5%; removing resistance distance drops cut-vertex to 83.3%; ZINC-subset MAE 0.081 vs Graphormer 0.122. Text/LM: none. — [arXiv 2301.09505](https://arxiv.org/abs/2301.09505); details from [ar5iv](https://ar5iv.labs.arxiv.org/html/2301.09505).

**Exphormer: Sparse Transformers for Graphs — Shirzad, Velingker, Venkatachalam, Sutherland, Sinop — ICML 2023 (PMLR 202:31613–31632).** Components: (b) attention support = local neighborhood edges ∪ random regular expander-graph edges ∪ virtual global nodes; plugged into GraphGPS. Datasets: 15 incl. CIFAR10, MNIST, PascalVOC-SP, COCO-SP, PATTERN, CLUSTER, MalNet-Tiny, Peptides, PCQM-Contact, Coauthor CS/Physics, ogbn-arxiv, Amazon Computer/Photo. Component-wise ablation: yes (Table 5): removing local edges / expander edges / global nodes changes CIFAR10 74.69 → 74.62 / 74.53 / 74.68 and Computer 91.43 → 90.34 / 91.48 / 91.59 — individual patterns are nearly interchangeable on these datasets. Text/LM: none (ogbn-arxiv node features are precomputed embeddings). — [arXiv 2303.06147](https://arxiv.org/abs/2303.06147); [PMLR page](https://proceedings.mlr.press/v202/shirzad23a.html); ablation from [arXiv HTML v2](https://arxiv.org/html/2303.06147v2).

**Graph Inductive Biases in Transformers without Message Passing (GRIT) — Ma, Lin, Lim, Romero-Soriano, Dokania, Coates, Torr, Lim — ICML 2023 (PMLR 202:23321–23337).** Components: (a)+(d)+(e) simultaneously: pair representation e_ij initialised with RRWP P_ij = [I, M, M², …, M^{K−1}]_ij (M = D⁻¹A); attention logit ê_ij = σ(ρ((W_Q x_i + W_K x_j) ⊙ W_Ew e_ij) + W_Eb e_ij) (multiplicative FiLM-style conditioning + additive bias, ρ = signed square root), α_ij = softmax_j(W_A ê_ij); value x̂_i = Σ_j α_ij (W_V x_j + W_Ev ê_ij) — i.e., the pair representation also enters the VALUE; pair representations are updated every layer; degree scaler injected per layer. Datasets: ZINC, MNIST, CIFAR10, PATTERN, CLUSTER, Peptides-func/struct, ZINC-full, PCQM4Mv2. Component-wise ablation: yes (Table 5, ZINC MAE): GRIT 0.059; remove degree scaler 0.076; remove RRWP update 0.066; global→sparse attention 0.066; degree scaler→Graphormer degree encoding 0.072; GRIT-attn→Graphormer-attn (scalar bias) 0.117; RRWP→RWSE 0.081; RRWP→SPDPE 0.067. Synthetic experiment: GRIT attention learns k-hop propagation matrices with error ≈0.001 vs Graphormer+SPDPE 0.025–0.043. Text/LM: none. — [arXiv 2305.17589](https://arxiv.org/abs/2305.17589); [PMLR PDF](https://proceedings.mlr.press/v202/ma23c/ma23c.pdf) (equations/ablation extracted from this PDF).

**SGFormer: Simplifying and Empowering Transformers for Large-Graph Representations — Wu, Zhao, Yang, Zhang, Nie, Jiang, Bian, Yan — NeurIPS 2023.** Components: (c) single-layer softmax-free linear attention Z = β D⁻¹[V + (1/N) Q̃(K̃ᵀV)] + (1−β) Z⁽⁰⁾ with Frobenius-normalised Q̃, K̃ (O(N)); combined with a GCN branch; no PE at all. Datasets: Cora, CiteSeer, PubMed, Actor, Squirrel, Chameleon, Deezer, ogbn-proteins, Amazon2M, pokec, ogbn-arxiv, ogbn-papers100M. Ablation: number of layers (more layers no gain, hurts on Actor); softmax variant OOMs at 40K nodes vs 1.5 GB for linear — no accuracy comparison of softmax vs linear is given; no PE ablation. Text/LM: none (ogbn-arxiv Word2Vec title/abstract averages only). — [arXiv 2306.10759](https://arxiv.org/abs/2306.10759); details from [arXiv HTML v5](https://arxiv.org/html/2306.10759v5).

**Attending to Graph Transformers — Müller, Galkin, Morris, Rampášek — TMLR (published 02/2024; arXiv v1 Feb 2023).** Taxonomy: PE/SE (local/global/relative); GNN as auxiliary module/structural prior; attention masking by graph structure; attention bias. Empirical findings: (Q1) on Edges/Triangles/CSL, Transformer+RWSE and Graphormer solve tasks almost perfectly but Graphormer is capped at 90% on CSL because "shortest-path distributions can only distinguish 9 out of the 10 classes"; Transformer+LapPE "sub-par on Triangles". (Q2) On small heterophilic datasets, "disabling the local GCN in GPS … increases the performance even further", and "Surprisingly, the attention bias of Graphormer had no impact … The shortest-path distance bias appears uninformative in these datasets, unlike, e.g., in Zinc, where we observed degradation from 0.12 test MAE to 0.54 when disabling the attention bias." On large heterophilic graphs, "positional/structural information can lead to large gains in performance, while global attention only provides small or no improvements at all." (Q3) GT fits NeighborsMatch to depth 6 but over-squashing is "not resolved by transformers". Text/LM: none. — [arXiv 2302.04181](https://arxiv.org/abs/2302.04181) (quotes from the PDF at that URL, header "Published in Transactions on Machine Learning Research (02/2024)").

**Transformers are Graph Neural Networks — Chaitanya K. Joshi — arXiv 27 June 2025 (technical version of the 2020 The Gradient article).** Not a method paper: argues self-attention = message passing on a fully-connected token graph, positional encodings supply structure, and Transformers are "GNNs currently winning the hardware lottery" because dense matmuls beat sparse message passing on accelerators. Text/LM: discusses NLP Transformers conceptually; no experiments. — [arXiv 2506.22084](https://arxiv.org/abs/2506.22084).

### Inferences
- The component most consistently shown to matter in controlled ablations is the pairwise score term (a): Graphormer's spatial+edge bias (0.2276 → 0.1304), GraphiT's kernel bias (0.696 → 0.243), GRIT's attention vs Graphormer-attention (0.059 vs 0.117), RT vs set-Transformer (81.3% vs 42.3%). Masking (b) alone was decisive only in the 2020 Dwivedi–Bresson setting (sparse ≫ full) and is nearly irrelevant in Exphormer's ablation once expander/global edges exist.
- Whether structure should also enter the value path (d) is rarely isolated: Shaw et al. (NLP) found a^V adds nothing over a^K; GRIT and RT put pair features into values but do not ablate that term separately; EGT's gating of values is reported as a "significant improvement" but without a clean row-wise number in the extracted text.
- The dataset dependence is strong: SPD bias is "uninformative" on heterophilic node tasks but worth 0.12 → 0.54 MAE on ZINC (Attending to GTs), and GraphGPS's global attention is useless on ZINC but needed on CIFAR10/MalNet.

### Gaps
- SAN's own ablation table (real vs virtual edge attention, LPE vs LapPE) was not extractable from the abstract page.
- NodeFormer's Appendix Table 6 (relational bias / edge regulariser ablation) numbers were not extracted.
- EGT Table 5 per-row numbers (gating / virtual node / PE on PCQM4Mv2) could not be mapped reliably from the HTML.
- GraphiT has no peer-reviewed venue on arXiv; treat as preprint.

## Key Question 2 — 2024–2026 work extending GRIT/GraphGPS-style "structure in attention without message passing"; design-space / factorial / benchmark studies

### Takeaway
2024–2026 produced (i) theory unifying PE types and biased attention (Black et al. ICML 2024; Stoll/Müller/Morris NeurIPS 2025 "GDT"), (ii) new relative encodings and attention masks (SPSE, X-LogSMask, GRASS/D-RRWP), (iii) sparser supports (Spexphormer), (iv) benchmarks that vary PE/attention across 13+ GT families (OpenGT 2025), but no paper runs a full factorial over all five attention components; the closest to a controlled single-architecture comparison of PEs and biased attention is the GDT paper.

### Cited Findings
- **Comparing Graph Transformers via Positional Encodings — Black, Wan, Mishne, Nayyeri, Wang — ICML 2024 (PMLR 235).** Defines APE (node-level, added to features; component (e)) vs RPE (pair-level, modifies the attention block; component (a)). Main theorem: for unfeatured graphs, APE-GTs and RPE-GTs are equivalent in distinguishing power (APE→RPE via DeepSets, RPE→APE via 2-EGN). Caveat: with node features, "RPEs can be stronger than APEs" and converting RPE→APE "can strictly reduce the graphs a transformer can distinguish". Experiments: CSL, BREC, ZINC (RD-RPE-GT edges out SPE-APE-GT on ZINC). Text/LM: none. — [arXiv 2402.14202](https://arxiv.org/abs/2402.14202); [ICML poster](https://icml.cc/virtual/2024/poster/32777); details from [arXiv HTML v4](https://arxiv.org/html/2402.14202v4).
- **Towards Principled Graph Transformers (Edge Transformer) — Müller, Kusuma, Bonet, Morris — NeurIPS 2024.** Global attention over node PAIRS (triangular attention); proven at least 3-WL expressive; outperforms theoretically aligned baselines "without using positional or structural encodings". Text/LM: none. — [arXiv 2401.10119](https://arxiv.org/abs/2401.10119).
- **Triplet Interaction Improves Graph Transformers (TGT) — Hussain, Zaki, Subramanian — ICML 2024 (PMLR 235).** Extends EGT with direct pair-to-pair ("triplet") attention/aggregation so neighbouring pairs communicate without routing through a node; molecular property prediction + TSP. Text/LM: none. — [arXiv 2402.04538](https://arxiv.org/abs/2402.04538); [PMLR](https://proceedings.mlr.press/v235/hussain24a.html).
- **Graph Transformers without Positional Encodings (Eigenformer) — Ayush Garg — arXiv 2024 (no venue).** Replaces PE with a "spectrum-aware attention mechanism" that factorises attention with Laplacian-spectrum information (component (a) instead of (e)); proves expressibility of connectivity matrices. Text/LM: none. — [arXiv 2401.17791](https://arxiv.org/abs/2401.17791).
- **Polynormer: Polynomial-Expressive Graph Transformer in Linear Time — Deng, Yue, Zhang — ICLR 2024.** Linear local-to-global attention (component (c)) where attention scores set coefficients of a high-degree equivariant polynomial; 13 homophilic/heterophilic datasets incl. million-node graphs; "outperforms state-of-the-art GNN and GT baselines on most datasets". Text/LM: none. — [arXiv 2403.01232](https://arxiv.org/abs/2403.01232).
- **Even Sparser Graph Transformers (Spexphormer) — Shirzad, Lin, Venkatachalam, Velingker, Woodruff, Sutherland — NeurIPS 2024.** Component (b): a narrow network estimates attention on the full Exphormer-augmented graph, then a wider network trains only on the high-scoring edges; theory on when narrow-network scores match wide-network scores. Text/LM: none. — [arXiv 2411.16278](https://arxiv.org/abs/2411.16278); [NeurIPS page](https://proceedings.neurips.cc/paper_files/paper/2024/hash/834fe9eecf8d1839f406a79c6982be05-Abstract-Conference.html).
- **Greener GRASS: Enhancing GNNs with Encoding, Rewiring, and Attention — Liao & Póczos — ICLR 2025.** Uses RRWP and a decomposed D-RRWP (truncated eigendecomposition) as encodings, rewires by adding a random regular graph, and uses an additive attention; reports 20.3% ZINC MAE reduction. Text/LM: none. — [arXiv 2407.05649](https://arxiv.org/abs/2407.05649).
- **Graph Transformers Dream of Electric Flow — Cheng, Carin, Sra — ICLR 2025.** A linear Transformer fed only the incidence matrix can implement electric-flow and Laplacian-eigenvector algorithms; on a molecular regression task it learned a PE outperforming the default Laplacian-eigenvector PE. Text/LM: none. — [ICLR 2025 proceedings](https://proceedings.iclr.cc/paper_files/paper/2025/hash/075b2875e2b671ddd74aeec0ac9f0357-Abstract-Conference.html); [arXiv 2410.16699](https://www.arxiv.org/abs/2410.16699).
- **Homomorphism Counts as Structural Encodings for Graph Learning (MoSE) — Bao, Jin, Bronstein, Ceylan, Lanzinger — ICLR 2025.** Motif structural encoding from homomorphism counts (component (e)); "outperforms other well-known positional and structural encodings across a range of architectures". — [ICLR 2025 page](https://proceedings.iclr.cc/paper_files/paper/2025/hash/f11b71773294e68ffc9ec6792dd9d163-Abstract-Conference.html); [arXiv 2410.18676](https://arxiv.org/abs/2410.18676v2).
- **Simple Path Structural Encoding for Graph Transformers (SPSE) — Airale, Longa, Rigon, Passerini, Passerone — arXiv Feb/May 2025 (no venue listed).** Edge (pair-level) encoding from simple-path counts, proposed as an alternative to RWSE/random-walk edge encodings, with an approximate counting algorithm; "statistically significant gains" on molecular and long-range benchmarks. Comparison to RRWP not on the abstract page. Text/LM: none. — [arXiv 2502.09365](https://arxiv.org/abs/2502.09365).
- **OpenGT: A Comprehensive Benchmark For Graph Transformers — Tang, Wang, Chen, Zhou, Chen, Bu — arXiv June 2025.** 13 GTs (DIFFormer, NodeFormer, GraphGPS, Graphormer, GRIT, SGFormer, SAN, SpecFormer, Exphormer, Graphtransformer, GraphMLPMixer, CoBFormer, DeGTA) + GCN/GAT/APPNP under one protocol. Findings: PE usefulness "varies depending on the specific dataset and model architecture"; GPS+RWSE ZINC MAE 0.0681 vs 0.1968 without; Graphormer degree encoding helps on dense node-level graphs (Chameleon/Squirrel); local-only attention (Graphtransformer, DeGTA) degrades on sparse/small/heterophilous graphs while global (Graphormer, GRIT) and hybrid (GPS, SGFormer) stay competitive; preprocessing cost on PubMed: RW stats ~10 min, spectral ~1 h, all-pairs SPD up to 2 h; node-level components "do not readily generalize" to graph-level tasks. Text/LM: none. — [arXiv 2506.04765](https://arxiv.org/abs/2506.04765); details from [arXiv HTML](https://arxiv.org/html/2506.04765).
- **Generalizable Insights for Graph Transformers in Theory and Practice (Generalized-Distance Transformer, GDT) — Stoll, Müller, Morris — NeurIPS 2025.** Standard softmax attention with a bias tensor B: Attention(Q,K,V,B) = softmax(d^{-1/2} QKᵀ + B) V, where B_ij = ρ(ℓ_E(i,j)) + U_ij W_U (edge embedding projected to heads + relative PE); the paper notes this one formula subsumes the local GT (B=0 on edges, −∞ otherwise), causal masking, and Shaw/ALiBi-style relative PEs. Theorem 1 / Insight 1: "The expressivity of biased attention can be characterized by the GD-WL"; GDT with no PE ≡ 1-WL. Insight 2: any of RWSE, RRWP, LPE, SPE strictly enhances expressivity; Theorem 2: RWSE incomparable to 1-WL; Prop. 3: RRWP strictly more expressive than RWSE at equal walk length; Prop. 4: SPE ⪰ LPE and RRWP, LPE ⪰ RWSE. Empirically (>8M graphs, ~270M tokens: PCQM4Mv2, COCO/PASCAL superpixels, ogbg-code2 summarisation, algorithmic OOD tasks, 15M–160M params): RRWP best on 4/6 tasks but expensive; RWSE and LPE "perform similarly", clearly better than NoPE and SPE; Insight 3: "PE efficiency can vary greatly while predictive performance differences are less pronounced". Text/LM: none (code summarisation uses AST tokens, no LM). — [NeurIPS 2025 PDF](https://proceedings.neurips.cc/paper_files/paper/2025/file/f79df6cbc6e5f708440004fad7ef64cc-Paper-Conference.pdf) (quotes extracted from this PDF).
- **Scaling Graph Transformers: A Comparative Study of Sparse and Dense Attention — Leon Dimitrov — arXiv Aug 2025 (no venue).** Narrative comparison of dense vs sparse attention supports (component (b)) and when to use each; no new quantitative ablation in the abstract. — [arXiv 2508.17175](https://arxiv.org/abs/2508.17175).
- **GraphTARIF: Linear Graph Transformer with Augmented Rank and Improved Focus — Hu, Li, Fan, Yang — WWW 2026.** Diagnoses linear attention's "overly uniform attention distributions" and low-rank maps; adds a gated local GNN branch on the value matrix (component (d)) and a learnable log-power on attention scores (component (c)) to lower entropy. Text/LM: none. — [arXiv 2510.10631](https://arxiv.org/abs/2510.10631).
- **Relational Graph Transformer (RelGT) — Dwivedi, Jaladi, Shen, López, Kanatsoulis, Puri, Fey, Leskovec — ICLR 2026.** Tokenises relational-database nodes into (features, type, hop distance, time, local structure) and combines local attention over sampled subgraphs with global attention to learnable centroids; up to 18% over GNNs on 21 RelBench tasks. Text/LM: not mentioned on the abstract page. — [arXiv 2505.10960](https://arxiv.org/abs/2505.10960).
- **X-LogSMask: Expand Transformer for Graph-Structured Data — Li, Yang, Zhang, Hu — arXiv 2 July 2026 (no venue).** Component (a)/(b) hybrid: adds M = log(Ã + ε), Ã = D^{-1/2}(A+I)D^{-1/2}, to the logits before softmax (acts as a soft multiplicative gate), head k uses log(Ã^k + ε) so each head has a fixed structural radius; Q/K/V unchanged; 20 benchmarks, SOTA on 13. Ablation: removing the log mask drops Cora 82.70 → 58.80; no direct PE-vs-mask comparison on graphs. Text/LM: none. — [arXiv 2607.01553](https://arxiv.org/html/2607.01553).
- **Transformers over Directed Acyclic Graphs — Luo, Thost, Shi — NeurIPS 2023.** Component (b)+(e): DAG attention restricted along the partial order plus DAG positional encoding (node depth); source-code graphs and citation networks. Text/LM: not stated on abstract page. — [arXiv 2210.13148](https://arxiv.org/abs/2210.13148); [NeurIPS page](https://proceedings.neurips.cc/paper_files/paper/2023/hash/94e85561a342de88b559b72c9b29f638-Abstract.html).
- Surveys: **Graph Transformers: A Survey — Shehzad, Xia, Abid, Peng, Yu, Zhang, Verspoor — IEEE TNNLS 2026 (arXiv 2407.09777, rev. Dec 2025)** organises inductive-bias injection into node positional encodings, edge structural encodings, message-passing bias and attention bias — [arXiv 2407.09777](https://arxiv.org/abs/2407.09777). **A Survey of Graph Transformers: Architectures, Theories and Applications — Yuan et al. — ACM Computing Surveys (arXiv 2502.16533, v3 Jul 2026)** categorises by graph tokenization, positional encoding, structure-aware attention, and model ensemble — [arXiv 2502.16533](https://arxiv.org/abs/2502.16533).

### Inferences
- The field converged on a single algebraic form — softmax(QKᵀ/√d + B)V with B built from edge embeddings and relative PEs (GDT) — as the "standard" way to put structure into attention; GRIT's multiplicative/value-side conditioning remains the main outlier, and no 2024–2026 paper I found ablates GRIT-style value-side pair features against the additive-bias-only GDT form on the same data.
- Factorial design-space studies in the GraphGym sense (You et al. 2020) do not exist for GT attention components; OpenGT and GDT are the closest (vary PE × architecture, or PE × scale on one architecture) but hold the attention form fixed.

### Gaps
- No 2024–2026 paper was found that factorially crosses {bias type} × {support} × {normalization} × {value transform}; this is an open gap.
- SPSE vs RRWP head-to-head numbers were not available from the abstract.
- Eigenformer's quantitative comparison vs GRIT/GPS was not extractable from the abstract page.

## Key Question 3 — Relation-specific value transforms vs shared values; softmax vs kernelized/linear/Gumbel; sparsemax/entmax on graphs

### Takeaway
Direct evidence on the value path comes from HGT (removing per-type/per-relation parameterisation costs ~4–6% NDCG), Shaw et al. (value-side relative term adds nothing once keys carry it), EGT (value gating "significant") and GRIT/RT (value-side pair features present but not ablated in isolation); softmax vs linear/Gumbel comparisons exist in NodeFormer (Gumbel > softmax by ~1–2 points), GraphGPS (Performer/BigBird < softmax) and GraphTARIF (linear attention too uniform/low-rank), while no paper applying sparsemax/entmax to graph transformers was found.

### Cited Findings
- **Heterogeneous Graph Transformer (HGT) — Hu, Dong, Wang, Sun — WWW 2020.** Component (d)+(a): node-type-specific K/Q/M(value)/A linear maps and edge-type-specific W^ATT_φ(e) (inside the score) and W^MSG_φ(e) (inside the message/value), plus a meta-relation prior μ; relative temporal encoding. Ablation on OAG Paper–Field L1 NDCG (Table 2): −RTE −Heter (shared weights) .571; +RTE −Heter .578; −RTE +Heter .595; full (+RTE +Heter) .615 — i.e., sharing the type/relation-specific weights costs .615 → .578 (the text says "removing heterogeneous parameterization drops performance by 4%"); parameter counts 3.12M / 3.88M / 7.44M / 8.20M; a fully per-relation-weight baseline ran out of GPU memory. Text/LM: YES — paper node features are pre-trained XLNet representations of titles (attention-weighted average); no LM is fine-tuned. — [arXiv 2003.01332](https://arxiv.org/abs/2003.01332); equations/ablation from [ar5iv](https://ar5iv.labs.arxiv.org/html/2003.01332).
- Shaw et al. 2018 value-side ablation (a^V adds 0.0 BLEU over a^K alone; a^V alone −0.5 BLEU): [ar5iv 1803.02155](https://ar5iv.labs.arxiv.org/html/1803.02155).
- GRIT value term x̂_i = Σ_j α_ij (W_V x_j + W_Ev ê_ij): structure enters the value via the pair representation; the ablation table removes RRWP update, degree scaler, sparse attention and the whole attention form, but not the W_Ev term alone — [PMLR GRIT PDF](https://proceedings.mlr.press/v202/ma23c/ma23c.pdf).
- RT: edge in V (v_ij = n_j W_n^V + e_ij W_e^V) is never ablated separately from edge in Q/K — [arXiv HTML 2210.05062v3](https://arxiv.org/html/2210.05062v3).
- EGT: sigmoid gating of values by edge channels gives a "significant improvement" on PCQM4Mv2 (Table 5); EGT-Simple without dedicated edge channels: ZINC 0.228 vs 0.108 — [arXiv HTML 2108.03348v3](https://arxiv.org/html/2108.03348v3).
- GraphGPS: Transformer (softmax) vs Performer vs BigBird on PCQM4Mv2-subset 0.1159 / 0.1142 / 0.1237 and CIFAR10 72.31 / 70.67 / 70.48 — "Performer falls behind Transformer … BigBird … offers no significant gain" — [arXiv 2205.12454](https://arxiv.org/abs/2205.12454).
- TokenGT: Laplacian-ID + Performer 0.0935 vs softmax 0.0910 PCQM4Mv2 valid MAE — [ar5iv 2207.02505](https://ar5iv.labs.arxiv.org/html/2207.02505).
- NodeFormer: kernelised Gumbel-softmax 77.45 (OGB-Proteins) / 87.85 (Amazon2M) vs plain kernelised softmax τ=1 75.50 / 87.02 and τ=0.25 76.18 / 87.55 — [arXiv HTML 2306.08385](https://arxiv.org/html/2306.08385).
- DIFFormer: cosine-linear vs sigmoid-quadratic diffusivity: mixed (Cora 85.9 vs 84.1; Citeseer 73.5 vs 75.7) — [arXiv HTML 2301.09474v4](https://arxiv.org/html/2301.09474v4).
- SGFormer: softmax variant OOMs at 40K nodes vs 1.5 GB linear; no accuracy comparison — [arXiv HTML 2306.10759v5](https://arxiv.org/html/2306.10759v5).
- GraphTARIF (WWW 2026): linear attention "loses expressiveness because of overly uniform attention distributions and low-rank projection structures"; remedies are a gated local GNN branch on V and a learnable log-power on scores — [arXiv 2510.10631](https://arxiv.org/abs/2510.10631).
- Polynormer keeps non-negativity and normalisation of softmax in a linear scheme; a third-party summary (not primary) says cosFormer-style linear attention failed on large graphs and a sigmoid feature map fixed it — [arXiv 2403.01232](https://arxiv.org/abs/2403.01232); [Lacuna summary (secondary)](https://lacuna.tiptreesystems.com/work/polynormer-polynomial-expressive-graph-transformer-in-linear-time/wrk_4a5a7217b6df23a44a9cd32d547635e6).
- Sparsemax/entmax: only NLP results were found — Adaptively Sparse Transformers (Correia, Niculae, Martins, EMNLP 2019) report small BLEU gains for α-entmax over softmax — [arXiv 1909.00015](https://arxiv.org/abs/1909.00015v2); a 2025–2026 line (ASEntmax) targets long-context LMs — [arXiv 2506.16640](https://arxiv.org/abs/2506.16640v3). No graph-transformer paper using sparsemax/entmax surfaced.
- X-LogSMask's log-normalised-adjacency logit term is effectively a soft (b)/(c) hybrid replacing hard masks — [arXiv 2607.01553](https://arxiv.org/html/2607.01553).

### Inferences
- The only clean "relation-specific vs shared" numbers are HGT's on heterogeneous academic graphs (~4–6% NDCG) and Shaw's on MT (value-side term redundant); taken together they suggest relation-specific parameters matter mostly when relation types carry distinct semantics (heterogeneous graphs) and that placing them in the score suffices when relations only encode geometry.
- Softmax remains the accuracy reference; kernelized/linear variants are adopted for memory, with the explicit cost documented by GraphGPS and the diagnosis (uniform, low-rank) given by GraphTARIF; Gumbel noise in NodeFormer is the one case where a non-softmax normalisation improved accuracy, framed as structure learning rather than efficiency.

### Gaps
- No paper found that ablates "edge features in V only" vs "in K only" on graphs (the Shaw-style ablation has not been replicated for graph transformers).
- No sparsemax/entmax graph-transformer study found.

## Key Question 4 — Is there a paper framing R-GCN / GAT / Transformer as points in one design space with a controlled factorial comparison?

### Takeaway
No paper was found that places R-GCN, GAT and the Transformer in a single parameterised design space and runs a controlled factorial comparison; the closest are the GDT paper (one biased-attention formula provably subsuming local GT/MPNN-attention, causal masking and relative PEs, but evaluated only over PE choices), the Relational Transformer's set-Transformer ablation on CLRS, and HGT's shared-vs-typed-weights ablation.

### Cited Findings
- GDT states that Equation (2) "is a general formulation whose special cases include the local GT [Dwivedi and Bresson, 2020], an attention-based variant of MPNNs with B_ij = 0 if nodes i and j share an edge and B_ij = −∞ else; attention with causal masking … as well as many relative PEs [Shaw et al., 2018, Beltagy et al., 2020, Press et al., 2022]" and claims GDT "captures MPNNs, most graph transformers, and many other transformer models" — but its experiments vary PEs and scale, not the mask/bias/value axes — [NeurIPS 2025 PDF](https://proceedings.neurips.cc/paper_files/paper/2025/file/f79df6cbc6e5f708440004fad7ef64cc-Paper-Conference.pdf).
- Graphormer claims "many popular GNN variants can be expressed as special cases of Graphormer" (abstract) — [arXiv 2106.05234](https://arxiv.org/abs/2106.05234).
- Relational Transformer vs GCN vs GAT on CLRS end-to-end: average relative loss 0.22 vs 0.45 (GCN) vs 0.28 (GAT); set-Transformer (edges removed) 42.34% vs 81.30% — [arXiv HTML 2210.05062v3](https://arxiv.org/html/2210.05062v3).
- HGT: removing per-type/per-relation parameterisation (i.e., collapsing toward a shared-weight GAT-like model) costs .615 → .595/.578 NDCG — [ar5iv 2003.01332](https://ar5iv.labs.arxiv.org/html/2003.01332).
- A secondary (aggregator) source states that in RGAT, "dropping the attention reverts RGAT to R-GCN and decreases performance by 1–2% in AUC or F1" — [EmergentMind RGAT topic page (secondary, unverified against the primary)](https://www.emergentmind.com/topics/relational-graph-attention-networks-rgat); the primary r-GAT paper is [arXiv 2109.05922](https://ar5iv.labs.arxiv.org/html/2109.05922) (not fetched).
- Joshi 2025 argues the conceptual equivalence (Transformer = GNN on complete graph) without experiments — [arXiv 2506.22084](https://arxiv.org/abs/2506.22084).

### Inferences
- A controlled factorial study with factors {support: neighbors / full}, {score: none / edge-type / distance}, {normalization: softmax / linear / Gumbel}, {value: shared / relation-specific / edge-conditioned} would be novel; the GDT formula provides the natural scaffold for it.

### Gaps
- Searches for "unified design space R-GCN GAT Transformer factorial" returned no primary paper; mark as "none found" rather than "does not exist".

## Key Question 5 — Text / pretrained LM involvement; what exists at the text+structure-in-attention intersection

### Takeaway
None of the canonical graph-transformer papers (Graphormer, SAN, GraphiT, EGT, SAT, GraphGPS, TokenGT, GRIT, Exphormer, SGFormer, GDT, OpenGT, Polynormer, X-LogSMask…) use text or a pretrained LM; NodeFormer/DIFFormer use TF-IDF, HGT uses frozen XLNet features. Structure-in-attention WITH a language model exists in a separate lineage — code/NLP relation-aware attention (RAT-SQL, GraphCodeBERT, Code Transformer, GREAT) and a 2025–2026 wave that injects SPD/RRWP/adjacency biases directly into LLM attention (UniGTE, GTLM, GaLA, Slash-the-Sink) — and these papers do ablate bias types, but none of them compares bias vs mask vs value transform factorially.

### Cited Findings (text/LM status per paper, then text+structure papers)
- Text/LM = none: Dwivedi–Bresson, Graphormer, SAN, GraphiT, EGT, SAT, GraphGPS, TokenGT, RT, Graphormer-GD, Exphormer, GRIT, SGFormer (Word2Vec features only on ogbn-arxiv), Attending-to-GTs, Black et al. 2024, Edge Transformer, TGT, Eigenformer, Polynormer, Spexphormer, GRASS, Electric Flow, SPSE, OpenGT, GDT, GraphTARIF, X-LogSMask (URLs given above in KQ1/KQ2).
- Text with TF-IDF only (no LM): NodeFormer and DIFFormer (20News-Groups) — [arXiv HTML 2306.08385](https://arxiv.org/html/2306.08385); [arXiv HTML 2301.09474v4](https://arxiv.org/html/2301.09474v4).
- Frozen LM features: HGT (XLNet title embeddings) — [ar5iv 2003.01332](https://ar5iv.labs.arxiv.org/html/2003.01332).
- **RAT-SQL — Wang, Shin, Liu, Polozov, Richardson — ACL 2020.** Relation-aware self-attention over question tokens + schema items: e_ij = x_i W_Q (x_j W_K + r^K_ij)ᵀ/√d, z_i = Σ α_ij (x_j W_V + r^V_ij), r^K = r^V = concat of learned embeddings per relation type (schema-graph edges: Same-Table, Foreign-Key, Primary-Key, Belongs-To; schema-linking edges: Exact/Partial/No name match, Column-Value). Uses BERT (65.6% Spider). Ablation (Spider dev, 5 seeds): full 55.13; w/o schema-linking relations 40.37; w/o schema-graph relations 35.59. — [ACL Anthology 2020.acl-main.677](https://aclanthology.org/2020.acl-main.677/); equations/ablation from [ar5iv 1911.04942](https://ar5iv.labs.arxiv.org/html/1911.04942).
- **GraphCodeBERT — Guo et al. — ICLR 2021.** Component (b) in a pretrained LM: graph-guided masked attention with M_ij = 0 if (q_i ∈ {[CLS],[SEP]}) or both tokens are code/comment, or (i,j) is a data-flow edge, or a variable-node↔code-token alignment edge; −∞ otherwise. Ablation (code search MRR): full 0.713, w/o EdgePred 0.707, w/o NodeAlign 0.703, w/o data flow 0.693. — [arXiv 2009.08366](https://arxiv.org/abs/2009.08366); mask/ablation from [ar5iv](https://ar5iv.labs.arxiv.org/html/2009.08366).
- **Language-Agnostic Representation Learning of Source Code from Structure and Context (Code Transformer) — Zügner, Kirschstein, Catasta, Leskovec, Günnemann — ICLR 2021.** Component (a) with TREE distances: XLNet-style relative attention with a separate key projection W_r^(s) per relation s ∈ {token sequence distance, AST shortest-path length, signed ancestor distance, signed sibling distance, −log personalized PageRank}, sinusoidal distance encoding binned into 32 bins; operates jointly over source tokens and AST nodes. Ablation (Java-small F1, structure-only, no pointer): sibling 46.17, shortest path 47.76, ancestor 47.89, PPR 48.47, all four 48.75; full model with pointer 52.22 vs context-only 50.34 vs structure-only 49.45. — [arXiv 2103.11318](https://arxiv.org/abs/2103.11318); details from [ar5iv](https://ar5iv.labs.arxiv.org/html/2103.11318).
- **Global Relational Models of Source Code (GREAT) — Hellendoorn et al. — ICLR 2020.** Edge-type bias added to Transformer attention over code tokens (VarMisuse). OpenReview page blocked by a verification wall; mechanism details UNVERIFIED in this session. — [OpenReview B1lnbRNtwr](https://openreview.net/forum?id=B1lnbRNtwr).
- **GraphFormers — Yang et al. — NeurIPS 2021.** Text-attributed graphs: GNN components nested between the Transformer blocks of a pretrained LM so text encoding and neighbour aggregation interleave (structure enters as extra tokens/aggregation, not as a bias on attention scores). — [arXiv 2105.02605](https://arxiv.org/abs/2105.02605).
- **Heterformer — Jin, Zhang, Zhu, Han — KDD 2023.** "Inject[s] heterogeneous structure information into each Transformer layer when encoding node texts" on text-rich heterogeneous networks; exact mechanism not on the abstract page. — [arXiv 2205.10282](https://arxiv.org/abs/2205.10282).
- **UniGTE — Wang, Zuo, Lu, Wu — NeurIPS 2025 (per arXiv comments).** Instruction-tuned encoder–decoder on a pretrained autoregressive LLM with "structure-aware graph-text attention" that is permutation-invariant to node order; search snippet (not verified on the abstract page) describes a learnable SPD lookup bias, edge biases from natural-language edge descriptions, and blocking text→graph attention. — [arXiv 2510.16885](https://arxiv.org/abs/2510.16885).
- **Teaching LLMs to See Graphs: Unifying Text and Structural Reasoning (GTLM) — Dario Vajda — arXiv 11 May 2026 (no venue).** Llama-3.2-1B/3B, Llama-3.1-8B + LoRA; component (a): learned lookup table of shape layers × heads × max_spd (=8) mapping SPD to an additive attention bias, plus RRWP and Magnetic-Laplacian biases; ~0.015% extra parameters. Ablation (GraphQA accuracy): removing Magnetic bias is worst (Edge Count 56.9 → 7.1; Shortest Path 90.1 → 76.3); removing SPD: Connected Nodes 90.7 → 81.4 but Shortest Path 90.1 → 92.0; removing RRWP: Edge Count → 48.9. Datasets: GraphQA, Cora, PubMed, OGBN-Arxiv, Reddit, synthetic KGQA. — [arXiv HTML 2605.10247v1](https://arxiv.org/html/2605.10247v1).
- **Formalizing and Mitigating Structural Distortion in LLM Attention for Graph Reasoning (GaLA) — Loveland, Trivedi, Weinstein, Huang, Koutra — KDD 2026.** Frozen Qwen2.5-3B/7B, Ministral-3B; component (a) at inference time: logit += λ_h · (1/d_G(i,j)) between node tokens, only in layers [0, L/2]; λ_h from attention entropy or one gradient pass. Gains: Cora semi-synthetic 69.3 → 87.9 (Ministral-3B); PubMed 77.5 → 82.5 (Qwen2.5-3B). Diagnosis: RoPE turns graph linearisation into "bandwidth-dependent attention decay". — [arXiv HTML 2606.15633](https://arxiv.org/html/2606.15633).
- **Slash the Sink: Sharpening Structural Attention Inside LLMs — Liu, Lu, Wang, Zhou, Jin — arXiv 18 May 2026 (no venue).** Component (c)-like intervention: training-free rescaling of attention weights (sink weight × γ, rest renormalised) in heads selected by entropy + adjacency-concentration; GraphInstruct average Llama-3.2-3B 0.085 → 0.214, Qwen3-8B 0.174 → 0.367; fine-tuned GraphWiz unchanged (0.642 → 0.639). — [arXiv HTML 2605.10503](https://arxiv.org/html/2605.10503).
- Search snippets also cite an EMNLP 2023 structure-aware KG-to-text model adding relative distance bias per layer and MGSA (arXiv 2409.10294); neither was fetched — [ACL Anthology 2023.emnlp-main.537](https://aclanthology.org/2023.emnlp-main.537.pdf) (unverified), [arXiv 2409.10294](https://arxiv.org/pdf/2409.10294) (unverified).

### Inferences
- The text+graph lineage reproduces the graph-transformer findings component by component — SPD/tree-distance biases (a) in Code Transformer, GTLM, GaLA; alignment-edge masks (b) in GraphCodeBERT; relation terms in K and V (a+d) in RAT-SQL — but each paper fixes all other components, so the question "which attention component carries the benefit when a pretrained LM is present" is unanswered.
- GTLM's finding that removing the SPD bias slightly *improves* shortest-path accuracy, and Attending-to-GTs' finding that SPD bias is uninformative on heterophilic graphs, both caution that distance-bias gains are task-specific even inside LLMs.

### Gaps
- GREAT's mechanism/ablation and UniGTE's attention details could not be verified (OpenReview wall; abstract-only page).
- No paper found that compares, inside one pretrained LM, (a) score bias vs (b) alignment masks vs (d) relation-specific values on text-attributed graphs.
